# 원칙 예외 기록

> 마지막 갱신: 2026-09-05
> 수정 이력은 이 파일을 고쳐 적지 말고 `git log`로 확인한다.

`CLAUDE.md`의 **★ 핵심 원칙**은 원칙이다. 반드시 지켜야 하는 법칙과는 다르지만, 가능한 한
따라야 하는 기준선이며 기본값은 항상 "지킨다"이다.

다만 특수한 경우에 한해 원칙을 위반할 수 있다. 그런 위반은 **기억에서 사라지면 안 되므로**
이 폴더에 기록으로 남긴다.

## 예외가 될 수 있는 경우

다음 중 하나에 해당해야 한다.

- 다른 대안이 없어 불가피한 경우
- 원칙을 지키는 방법보다 예외의 방법이 지나치게 압도적으로 이득이 큰 경우 (그 판단은 사람이 한다)
- 원칙을 지키는 방법보다 예외의 방법이 기능을 구현하는 가장 근본적으로 정확한 방법인 경우

세 가지 모두 **사람이 판단한다.** 에이전트나 기여자가 "이득이 크다"거나 "이쪽이 더 정확하다"고
스스로 결론내어 원칙을 비켜가지 않는다. 판단의 근거를 갖추어 사람에게 가져가는 것까지가
에이전트의 일이다.

## 위반할 때 지켜야 하는 절차

1. **사용자의 직접적인 판단을 반드시 득한다.** 에이전트나 기여자가 스스로 판단해 원칙을
   위반하지 않는다.
2. **왜 그 판단을 했는지 이 폴더에 문서로 남긴다.** 커밋 대상이며, 파일명에 **이슈 또는 PR
   번호를 반드시 포함**한다. 문서 상단에는 마지막 갱신일시와, 수정 이력은 git으로 확인하라는
   문구를 넣는다.
3. **`CLAUDE.md`의 해당 원칙 바로 아래에 불렛포인트로 그 문서를 링크한다.** 원칙을 읽는
   사람이 예외의 존재를 같은 자리에서 보게 하기 위함이다.

## 파일명 규칙

```
NNN-짧은-주제.md      NNN = 이슈 또는 PR 번호
```

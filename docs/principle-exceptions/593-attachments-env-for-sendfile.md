# CLI를 띄울 때 문서화되지 않은 환경변수 `CLAUDE_CODE_ATTACHMENTS_BY_PATH=1`을 준다

> 마지막 갱신: 2026-10-26
> 수정 이력은 이 파일을 고쳐 적지 말고 `git log -- docs/principle-exceptions/593-attachments-env-for-sendfile.md`로 확인한다.

- 관련 이슈: [#593](https://github.com/Swttch/swttch/issues/593) (Claude가 보낸 파일·그림·페이지를 채팅에서 Claude Code 데스크탑처럼 보여 달라는 요청)
- 관련 PR: [#602](https://github.com/Swttch/swttch/pull/602)

## 어떤 원칙을 위반하는가

`CLAUDE.md`의 **★ 핵심 원칙** 중 **2번 「공식 지원 비의존」**이다. `CLAUDE_CODE_ATTACHMENTS_BY_PATH`는 CLI가 소스 안에서 읽는 환경변수이고 공식 문서에 없다. 원칙 문장은 고치지 않았고, 여기 예외로 남긴다.

## 무엇이 문제였나

터미널의 `claude`에서는 Claude가 `SendUserFile` 도구로 사용자에게 파일이나 그림을 건넬 수 있다. 플러그인이 띄우는 `-p --input-format stream-json` CLI에는 이 도구가 없다. 2026-10-26에 같은 폴더에서 `claude -p`로 "SendUserFile 도구가 있느냐"고 물어 측정했다.

| 환경변수 | 답 |
|---|---|
| 없음 | 없다 |
| `CLAUDE_CODE_ATTACHMENTS_BY_PATH=1` | 있다 |

CLI 2.1.308 소스에서 `SendUserFile`의 사용 가능 여부 판정이 이 변수를 읽는 것을 확인했다. 그래서 플러그인에서 만든 세션은 파일을 건네지 못하고, 건네지 못하니 채팅에 카드도 생기지 않으며, 건넨 시점에 파일 복사본을 남기는 기능(삭제된 뒤에도 카드가 그려지게 하는 기능)도 일어나지 않았다.

## 선택지

| 방법 | 결과 |
|---|---|
| 아무것도 하지 않는다 | 플러그인 세션에서는 Claude가 파일을 건네지 못한다. 터미널과 다르다 |
| claude.ai에 올라간 파일을 가져온다 | 건넨 파일의 바이트는 claude.ai에만 있고 JSONL에는 `file_uuid`만 남는다. 가져오려면 claude.ai 로그인과 비공식 API가 필요해 원칙 2번을 더 크게 어긴다 |
| **CLI를 띄울 때 `CLAUDE_CODE_ATTACHMENTS_BY_PATH=1`을 준다** | 도구가 돌아온다. 도구 결과(`attachments[{path,size,isImage,...}]`)는 CLI가 돌려주는 그대로 쓴다 |

## 어느 기준으로 예외가 되는가

[README](./README.md)의 **첫 번째(다른 대안이 없어 불가피한 경우)** 와 **세 번째(가장 근본적으로 정확한 방법)** 에 해당한다. 터미널 사용자가 공짜로 받는 도구를, 우리가 CLI를 띄우는 방식 때문에 받지 못하는 차이를 없애는 일이다.

## 위반의 범위를 어떻게 좁혔는가

- **보내는 것은 환경변수 하나뿐이다.** 요청·응답 형식을 새로 가정하지 않는다.
- **사용자가 이미 정한 값이 이긴다.** 셸에 이 변수가 정의돼 있으면(끄기 값, 빈 문자열 포함) 건드리지 않는다. 값이 없을 때만 `1`을 채운다. (`buildAttachmentsEnv`)
- **다른 조건은 CLI의 것 그대로다.** 계정이나 정책이 도구를 막으면 막힌 채로 둔다.
- **변수가 사라져도 망가지지 않는다.** CLI가 읽지 않게 되면 플러그인 세션에서 `SendUserFile`이 빠질 뿐이다. 이는 이 예외를 철회하는 신호다.

## 이 예외가 정당하지 않게 되는 조건

- 공식 문서나 `claude --help`에 헤드리스 세션에서 `SendUserFile`을 켜는 방법이 생기는 경우: 그 방법으로 갈아탄다.
- CLI가 헤드리스 세션에도 기본으로 도구를 주는 경우: 변수가 불필요해진다.
- 이 변수를 주면 터미널에는 없는 동작이 생기는 경우.

## 확인하지 못한 것

- 2.1.308 외의 CLI 버전.
- 이미 Claude 데스크탑이 보낸 파일: 바이트가 claude.ai에만 있어 플러그인에서는 그려지지 않는다. 이 예외는 앞으로 플러그인 세션에서 보내는 파일만 다룬다.

# 모든 세션에서 모든 명령어 허용

> 언어: [English](./en.md) · **한국어**

[이번 세션에서 모든 명령어 허용](../081-allow_all_commands_in_session/ko.md)은 바이패스 모드에서도 Claude Code가 위험 경고로 보내는 승인 패널을 잠잠하게 만듭니다. 한계가 하나 있습니다. 대화 하나에서만 유지된다는 점입니다. 새 대화를 열면 패널이 돌아오고, 스위치를 다시 켜야 합니다.

이 기능은 그 마지막 한 걸음을 없앱니다. 후원자는 **모든 세션**에서 켜 둘 수 있어서, 새 대화가 처음부터 원하는 상태로 시작합니다. 세션 하나만 따로 끄는 것도 언제든 가능합니다.

> **한 세션을 넘어 켜 두는 것은 후원자 기능입니다.** 컨트롤은 모두에게 보이므로 동작 방식을 그대로 확인할 수 있습니다. 세션 하나에서 켜는 것은 지금까지처럼 무료입니다. Claude Code with GUI는 계속 무료이며, 후원은 이 독립적인 JetBrains-우선 프로젝트를 계속 나아가게 하는 방법입니다. 그리고 이 기능과 다른 모든 후원자 기능을 여러분에게 열어 줍니다.

## 무엇이 달라지는가

| | 전 | 지금 |
|---|---|---|
| 새 대화 | 스위치가 꺼진 채로 시작합니다. | 기본값이 정한 대로 시작합니다. |
| 켜는 방법 | 세션마다 경고창을 거칩니다. | 한 번으로 모든 세션에 적용됩니다. |
| 계속 물어야 하는 세션 | 할 일이 없었습니다. 꺼진 채 시작했으니까요. | 그 세션의 스위치를 끕니다. |

그 밖의 내용은 [이번 세션에서 모든 명령어 허용](../081-allow_all_commands_in_session/ko.md)에 적힌 그대로입니다. 보이는 경고창, 이 기능이 다루는 안전 확인과 다루지 않는 것까지 모두요.

## 경고창에서 켜기

경고창은 작업 도중에 만납니다. 바이패스 모드에서 흐려진 승인 항목의 **활성화**를 누르거나, 슬래시 커맨드 패널에서 **이번 세션에서 모든 명령어 허용**(영어 화면에서는 "Allow all command in this session")을 켤 때입니다. 이제 경고창의 본문 아래에 작은 상자 **모든 세션에서 활성화**(영어 화면에서는 "Enable in all sessions")가 있습니다. 후원자 기능을 뜻하는 파란 **S** 배지가 붙어 있고, 그 아래 한 줄이 상자를 켜면 무엇이 되는지 알려 줍니다.

![경고창 "Enable “Allow all command in this session”?". 네 문단 아래에 파란 S 배지가 붙은 체크된 상자 "Enable in all sessions"와 그 아래 문장 "Every session you open from now on will start with this allowed. You can turn it off in Settings > Permissions under “Allow all command in all sessions”."가 있습니다. 버튼은 "Cancel"과 붉은 "Enable"입니다.](./assets/warning-checkbox-on.png)

상자는 지금 설정이 있는 자리에서 시작합니다. 기본값을 켜 두지 않았다면 비어 있습니다.

![같은 경고창에서 상자 "Enable in all sessions"가 비어 있는 모습.](./assets/warning-checkbox-off.png)

**활성화**를 눌렀을 때 일어나는 일은 상자에 따라 갈립니다.

- **체크됨.** 이 세션이 켜지고, 지금부터 열리는 모든 세션도 켜진 채로 시작합니다.
- **비어 있고, 기본값이 꺼져 있었음.** 이 세션만 켜집니다. 기본값은 꺼진 채로 남습니다.
- **비어 있고, 기본값이 켜져 있었음.** 이 세션은 켜지고, 기본값은 **꺼집니다.** 기본값이 켜져 있으면 상자가 체크된 채 시작하므로, 상자를 비우는 것이 다른 모든 세션에 대해 되돌리는 방법입니다.
- **취소 또는 Esc.** 아무것도 바뀌지 않습니다. 세션도 기본값도 그대로입니다.

상자가 지금 설정에서 시작하기 때문에, 상자를 건드리지 않고 **활성화**를 눌러도 기본값은 절대 바뀌지 않습니다.

## 설정에서 켜기

같은 기본값은 **설정 → 권한**에도 스위치가 있습니다. 이제 이 화면은 카드 하나이고 권한 행 세 개가 한데 모여 있으며, 새 행이 **모든 세션에서 모든 명령어 허용**(영어 화면에서는 "Allow all command in all sessions")입니다. 파란 **S** 배지가 붙어 있습니다.

![설정 → 권한. 카드 하나에 "Disable Bypass Mode", "Default Input Mode", "Allow all command in all sessions"가 있고, 마지막 행에는 파란 S 배지와 꺼진 스위치가 있습니다.](./assets/settings-switch-off.png)

스위치를 켜면 모든 세션 기준으로 쓴 경고창이 열립니다. 알리는 내용은 같고, 끄는 곳으로 설정 → 권한을 알려 줍니다.

![네 문단과 "Cancel", 붉은 "Enable" 버튼이 있는 경고창 "Enable “Allow all command” in all sessions?". 이 창에는 상자가 없습니다.](./assets/warning-all-sessions.png)

여기에 상자가 없는 이유는, 스위치를 켠다는 것이 이미 모든 세션을 뜻하기 때문입니다. 켜려면 **활성화**를, 꺼 두려면 **취소**를 고르세요.

![설정 → 권한에서 "Allow all command in all sessions" 스위치가 켜진 모습.](./assets/settings-switch-on.png)

스위치를 끄는 데는 확인이 필요 없습니다. 승인 패널이 돌아올 뿐이니까요.

## 세션은 여전히 스스로 정합니다

`/`로 슬래시 커맨드 패널을 열고 **이번 세션에서 모든 명령어 허용**을 찾아보세요. 기본값이 켜져 있으면, 새 대화에서 그 스위치가 이미 켜져 있습니다.

![슬래시 커맨드 패널을 "allo"로 거른 모습. "Model" 아래 "Allow all command in this session"의 스위치가 켜져 있습니다. 이 대화에서는 아무것도 켜지 않았습니다.](./assets/session-switch-on.png)

거기서 끄면 **이 세션만** 다시 묻습니다.

![같은 슬래시 커맨드 패널에서 "Model" 아래 "Allow all command in this session"의 스위치가 꺼진 모습.](./assets/session-switch-off.png)

- 세션의 스위치를 끄는 데는 확인이 필요 없습니다. 다시 켜면 상자가 있는 경고창이 열립니다.
- 스스로 정한 세션은 그 선택을 지킵니다. 아직 정하지 않은 세션은 기본값을 따르므로, 기본값을 바꾸면 정하지 않은 열린 세션에 바로 반영됩니다.
- 첫 메시지를 보내기 전의 대화도 같은 규칙입니다. 첫 메시지 전에 스위치를 꺼 두면, 그 메시지가 만드는 세션이 꺼진 채 시작합니다.
- 세션 스위치와 기본값은 하나의 설정을 이루는 두 겹입니다. 슬래시 커맨드 패널의 스위치는 기본값을 절대 바꾸지 않습니다.

## 후원자가 아니라면

두 컨트롤 모두 화면에 남아 있습니다. 숨겨지지도, 막다른 길이 되지도 않습니다.

**설정 → 권한**에서는 스위치가 흐리게 꺼져 있습니다. 배지에 마우스를 올리면 "후원자 전용 기능"이라고 나옵니다. 스위치를 누르면 **설정 → 후원**이 열립니다. **설정 열기 방식**(영어 화면에서는 "Open Settings as") 선택에 따라 오버레이나 새 탭으로 열립니다.

![설정 → 권한에서 "Allow all command in all sessions" 스위치가 흐리게 꺼져 있고, 파란 S 배지 위에 작은 안내 "Sponsor-only feature"가 떠 있는 모습.](./assets/settings-switch-locked.png)

경고창에서는 상자가 흐리게 표시되고 체크할 수 없습니다. 상자나 그 글자를 누르면 **경고창이 닫히고** **설정 → 후원**이 열립니다. 경고창이 먼저 닫히는 이유는, 경고창이 키보드 포커스를 잡고 있어서 보내려는 화면 위에 그대로 남아 있을 수 없기 때문입니다.

![경고창 "Enable “Allow all command in this session”?". 흐려진 빈 상자 "Enable in all sessions"와 그 아래 안내 문장이 있습니다.](./assets/warning-checkbox-locked.png)

세션 하나에서 켜는 것은 계속 무료입니다. 상자를 건드리지 않고 **활성화**를 누르면 세션은 늘 하던 대로 켜집니다.

후원자 확인 결과를 앱이 아직 받지 못했을 때는 아무것도 흐려지지 않습니다. 상태를 불러오는 동안 후원자에게 잠금이 번쩍 보이는 일은 없습니다.

## 후원이 끝나면

정해 둔 설정은 그대로 남습니다. 후원자가 아닌 동안에는 적용만 멈추고, 기본값을 따르던 모든 세션에서 안전 확인 패널이 돌아옵니다. 직접 켠 세션은 그 스위치가 무료이므로 켜진 채로 남습니다. 후원이 다시 이어지면 설정도 남겨 둔 그대로 돌아옵니다.

## 선택이 저장되는 곳

기본값은 사용자 설정, 즉 `~/.claude-code-gui/settings.js`의 `allowAllCommandsByDefault`에 저장됩니다. 켜기 전에는 꺼져 있습니다.

**사용자 설정에만** 있습니다. **프로젝트 설정 (로컬)** 탭에서는 이 행이 흐리게 표시되고, 툴팁이 "Only available as a global setting"(영어로만 표시됩니다)이라고 알려 줍니다.

의도한 동작입니다. 프로젝트의 설정 파일은 저장소 안(`.claude-code-gui/settings.json`)에 있어서, 여러분이 복제한 저장소가 이 설정을 켠 채로 들어 있으면 그것을 여는 모든 사람의 경고가 꺼질 수 있습니다. 그래서 프로젝트 파일에 적힌 값은 무시합니다. 이 키를 조금이라도 가진 프로젝트는 꺼진 것으로 읽으며, 프로젝트가 스스로 빠질 수는 있어도 여러분을 대신해 켤 수는 없습니다.

## 어디까지 해당하고 어디는 해당하지 않는가

- **전과 같은 안전 확인.** Claude Code가 답을 기억하지 않는 질문들입니다. 그 밖의 승인 패널은 늘 그랬듯 뜹니다. [이번 세션에서 모든 명령어 허용](../081-allow_all_commands_in_session/ko.md#어디까지-해당하고-어디는-해당하지-않는가)을 보세요.
- **명령을 검사하지 않습니다.** 켜 두면 그런 명령이 여러분이 살펴보지 않아도 실행됩니다. Claude가 하는 일을 신뢰하는 곳에서 쓰세요.
- **권한 모드를 바꾸지 않습니다.** 모드는 그대로입니다.
- **오래된 Claude Code 버전.** Claude Code가 앱에 답을 기억하지 않겠다고 알려 주어야 동작합니다. 알려 주지 않는 버전이라면 패널은 그대로입니다.
- **잠깐 늦을 수 있습니다.** 패널이 열린 직후, 앱이 후원 여부를 읽기 전에 도착한 요청에는 패널이 뜰 수 있습니다.

## 자주 묻는 질문

**설정에서 켰는데 어떤 세션에서는 패널이 뜹니다. 왜 그런가요?**
다섯 가지가 가능합니다. 그 세션이 자기 스위치를 껐거나, 프로젝트 파일에 이 키가 있거나, 후원이 끝났거나, 앱이 후원 여부를 읽기 전에 안전 확인이 도착했거나, 지금 뜬 패널이 안전 확인이 아니라 일반 승인인 경우입니다. 그 세션의 슬래시 커맨드 패널을 열어 스위치를 보세요.

**모든 세션에서 끄려면 어떻게 하나요?**
**설정 → 권한**에서 스위치를 끄거나, 경고창에서 상자를 비우고 **활성화**를 누르세요. 앞의 방법은 확인이 필요 없습니다.

**세션 하나만 끄려면 어떻게 하나요?**
그 세션의 슬래시 커맨드 패널에서 **이번 세션에서 모든 명령어 허용**을 끄세요. 기본값과 다른 세션은 건드리지 않습니다.

**후원자인데 컨트롤이 흐리게 보입니다. 왜 그런가요?**
앱이 이 기기에서 후원자가 아니라고 읽을 때만 흐려집니다. **설정 → 후원**에서 이 기기의 상태를 확인하세요.

**상자를 눌렀더니 경고창이 닫힌 이유는요?**
경고창이 키보드 포커스를 잡고 있어서, 보내려는 화면 위에 열린 채로 있을 수 없습니다. 이 세션만 켜고 싶었다면 상자를 건드리지 않고 **활성화**를 누르세요.

**프로젝트가 대신 켜 줄 수 있나요?**
아니요. 프로젝트 파일은 이 설정을 켤 수 없습니다. 이 프로젝트에서는 켜지 말라고 말할 수 있을 뿐입니다.

**권한 모드가 바뀌거나 Claude가 더 많은 일을 하게 되나요?**
아니요. 한 종류의 질문에 누가 답하느냐만 바뀝니다. 바이패스 모드에서도 Claude Code가 묻는 그 안전 확인입니다.

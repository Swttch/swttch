# 직접 연결한 모델도 이름 그대로 표시됩니다

> 언어: [English](./en.md) · **한국어**
>
> 관련: [#217](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/217), [#202](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/202)

## 제보

한 사용자가 모델을 Haiku 자리로 바꿨습니다. 바꾼 직후에는 화면에 제대로 표시됐는데,
메시지를 보내 대화가 시작되자 입력창 아래 표시가 슬그머니 **Default** 로 돌아가
있었습니다. 그 화면을 캡처해 [#217](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/217)
로 알려주셨고, 2분 뒤 댓글로 한 장을 더 붙였습니다. 입력창 아래 줄이 두 줄로
쪼개져 무너진 모습이었습니다.

두 번째 스크린샷이 결정적이었습니다. 거기에 모델 목록이 이렇게 찍혀 있었습니다.

| 목록에 뜬 이름 | 그 아래 설명 |
|---|---|
| Default (recommended) | Use the default model (currently glm-5.2-mayi[1m]) |
| glm-5.2-mayi | Custom Opus model |
| glm-5.1-mayi | Custom Fable model |
| glm-4.7-mayi | Custom Sonnet model |
| glm-4.5-air-mayi | **Custom Haiku model** |

이 사용자는 Anthropic 모델이 아니라 **직접 연결한 다른 모델**을 쓰고 있었습니다.
Claude Code는 이런 연결을 정식으로 지원합니다. Opus·Sonnet·Haiku 같은 "자리"에
원하는 모델을 끼워 넣으면, 목록에는 그 모델의 진짜 이름이 뜨고 설명에 어느 자리인지
적힙니다.

## 실제로 벌어지던 일

먼저 분명히 해둘 것이 있습니다. **모델 전환 자체는 제대로 되고 있었습니다.**
제보자가 첫 스크린샷에서 "너는 무슨 모델이냐"고 묻자, 모델은 자기가
GLM-4.5-Air-MAYI라고 정확히 답했습니다. 바꾼 대로 동작하고 있었던 겁니다.
거짓말을 한 건 화면 표시뿐이었습니다.

원인은 화면이 "지금 어느 모델이지?"를 알아내는 방법에 있었습니다. 그 방법은
**모델 이름에 opus·sonnet·haiku 같은 단어가 들어 있는지 보는 것**이었습니다.
Anthropic 모델은 이름 자체가 `claude-haiku-4-5` 라서 이 방법이 늘 통했습니다.

그런데 `glm-4.5-air-mayi` 에는 그런 단어가 없습니다. 그래서 목록에 있는 다섯 개가
**전부 "모르겠음"으로 분류**됐고, 모를 때 집어들도록 돼 있던 것이 하필
Default 항목이었습니다.

여기까지가 첫 번째 증상입니다. 그리고 Default 항목의 설명은 짧은 이름이 아니라
`Use the default model (currently glm-5.2-mayi[1m])` 라는 **문장 하나**였습니다.
그 문장이 그대로 입력창 아래 줄에 들어가면서, 자리를 못 이기고 두 줄로 접혔습니다.
제보자가 두 번째로 올린 그 화면입니다.

증상은 둘이었지만 뿌리는 하나였습니다.

## 무엇을 고쳤나

**모델을 알아보는 방법을 넓혔습니다.** 이름만 보고 판단하던 것을, 이름으로
모르겠으면 **Claude Code가 알려준 설명까지 보도록** 했습니다. `Custom Haiku model`
이라고 적혀 있으면 Haiku 자리라는 뜻이니까요. 우리가 추측하는 것이 아니라 이미
받아둔 정보를 마저 읽는 것뿐입니다. 이름이 분명할 때는 여전히 이름이 우선입니다.

**대화가 시작돼도 고른 모델을 계속 표시합니다.** 대화가 시작되면 Claude Code가
지금 쓰는 모델을 다시 알려주는데, 그 형태가 목록에 적힌 것과 조금씩 다릅니다
(`glm-4.5-air-mayi[1m]` 처럼 뒤에 뭔가 붙거나 대소문자가 다르거나). 이제 이런
차이를 감안해서 맞춰보기 때문에, 사용자가 고른 그 모델이 화면에 그대로 남습니다.

**이름표는 이름답게 짧게 답니다.** 직접 연결한 모델은 설명 대신 진짜 이름
(`glm-4.5-air-mayi`)을 표시합니다. 긴 문장이 이름표 자리에 들어가는 일은 이제
없습니다.

**입력창 아래 줄이 무너지지 않습니다.** 이름이 아무리 길어도 한 줄을 유지하고,
넘치면 끝을 `…` 로 줄입니다. 전체 이름은 마우스를 올리면 나옵니다. 이건 모델
이름에만 해당하는 이야기가 아니라 그 줄 전체에 적용돼서, 제보자 화면에서 함께
쪼개져 있던 권한 표시("Bypass permissions")나 사용량 표시도 같이 한 줄로
유지됩니다. 창을 좁게 쓰거나 번역된 문구가 긴 언어를 쓸 때도 마찬가지입니다.

## Anthropic 모델을 쓰던 분들께

달라지는 것이 없습니다. `Opus 5`, `Haiku 4.5` 처럼 보이던 이름표는 그대로입니다.
이번 수정은 이름만으로 알아볼 수 없을 때 한 번 더 보는 단계를 덧붙인 것이라,
기존에 잘 되던 경로는 건드리지 않았습니다.

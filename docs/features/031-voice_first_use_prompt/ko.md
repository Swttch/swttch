# 쓰지 않을 음성 입력은, 이제 끌 수 있습니다

관련 이슈: [#299](https://github.com/Swttch/swttch/issues/299)

음성 입력은 켜진 채로 시작합니다. 그런데 실제로 쓰려면 도구(`@swttch/extend-kit`)를 설치해야 하고, 회사 정책 등으로 설치할 수 없는 환경에서는 **쓰지도 못하는 마이크 버튼이 계속 남아 있었습니다.**

이제 두 가지가 달라졌습니다.

## 도구를 설치하지 않아도 끌 수 있습니다

**설정 → 일반 → 음성 입력**의 "음성 입력" 토글을 끄면 됩니다.

![설정의 음성 입력 섹션. 도구가 없어 우측에 Install 버튼과 안내 문구가 있지만, "Voice input" 토글은 선명하게 켜져 있고 그 아래 사용 언어·대기 시간·단축키 세 줄만 흐리게 잠겨 있다](./assets/settings-voice-section.png)

이 토글은 원래도 있었습니다. 다만 도구가 없으면 이 섹션 전체가 잠겨서 **누를 수가 없었습니다.** 정작 도구를 설치하지 못하는 사람이 끄지도 못했던 셈입니다.

이제 도구 설치 여부와 관계없이 켜고 끌 수 있습니다. 아래 세 줄(사용 언어·대기 시간·단축키)은 도구가 있어야 의미가 있으므로 그대로 잠깁니다.

## 설정까지 찾아가지 않아도, 마이크를 누른 자리에서 정할 수 있습니다

마이크 버튼은 처음부터 보입니다. 눌러봐야 무엇인지 알 수 있으니 숨기지 않습니다.

**처음 누르면** 녹음이 시작되기 전에 한 번 물어봅니다.

![음성 입력을 쓸지 묻는 창. 제목 "Try speaking instead of typing?", 무엇을 설치하는지와 사용하지 않으면 어떻게 되는지 두 문단, 아래에 "Don't use"와 "Install and use" 버튼, 우측 상단에 닫기 버튼](./assets/first-use-dialog.png)

**사용 안 함**을 고르면 위 설정의 토글을 끈 것과 **똑같이 동작합니다.** 설정 화면을 찾아갈 필요 없이 그 자리에서 끝납니다.

이 질문은 **한 번만** 뜹니다. 답하고 나면 다시 나타나지 않습니다.

## 마이크 버튼이 사라집니다

끄기 전과 후입니다.

![입력창 오른쪽 끝에 마이크 아이콘이 있다](./assets/composer-mic-shown.png)

![같은 입력창에서 마이크 아이콘이 사라졌다](./assets/composer-mic-hidden.png)

단축키(기본 `⌥D`)도 함께 동작하지 않습니다. 도구는 설치되지 않습니다.

## "설치하고 사용"을 골랐다면

도구를 설치합니다. 설치 방식은 그 머신을 관리하는 패키지 매니저(volta·pnpm·yarn·npm 등)를 따릅니다 — 자세한 규칙은 [음성 입력 문서](../029-voice_to_text/ko.md)에 있습니다.

**설치가 끝나도 녹음은 바로 시작하지 않습니다.** 완료 안내가 뜨면 마이크를 다시 눌러 주세요. 이후로는 질문 없이 바로 녹음됩니다.

설치에 실패하더라도 다음에 다시 묻지는 않습니다. "쓰겠다"는 답은 그대로 남습니다.

## 지금 정하기 싫다면 닫아도 됩니다

우측 상단 **X 버튼**, 창 **바깥 클릭**, `Esc` 키로 닫을 수 있습니다.

다만 **닫는 것은 "사용 안 함"이 아닙니다.** 아무것도 정해지지 않은 채로 남고, 다음에 마이크를 누르면 **다시 묻습니다.**

여기서 "사용 안 함"은 창을 접는 것이 아니라 기능을 꺼버리는 선택이라, 무심코 누른 `Esc` 하나가 그 결과를 만들면 안 되기 때문입니다.

## 이미 도구가 있다면 묻지 않습니다

이미 도구를 가진 분에게 "설치하시겠습니까"는 물을 이유가 없으므로, 마이크를 누르면 곧바로 녹음이 시작됩니다.

터미널에서 직접 설치한 경우도 마찬가지입니다.

## 도구를 지웠다면

한 번 답한 뒤에 도구를 지우면(터미널에서 지우거나, 설정에서 휴지통을 누른 경우) 질문은 다시 뜨지 않습니다. 이미 답했기 때문입니다.

그때는 마이크를 눌렀을 때 입력창 위에 뜨는 안내줄의 **설치** 버튼으로 되돌립니다.

![입력창 위에 "Voice input needs @swttch/extend-kit" 안내줄이 뜨고, 오른쪽에 Install 버튼이 있다](./assets/banner-install.png)

## 참고

음성 입력을 켜고 끄는 설정은 우리가 따로 만든 것이 아니라 **Claude Code의 기본 설정**입니다. 터미널에서 `/voice`로 켜고 끄는 그 값과 같습니다.

그래서 여기서 끄면 **터미널의 음성 받아쓰기도 함께 꺼집니다.** 한 대의 컴퓨터에 하나의 답을 유지하기 위한 것입니다.

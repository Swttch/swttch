# "편집마다 그만 물어봐"가 이제 실제로 동작합니다

> 언어: [English](./en.md) · **한국어**

## 무엇이 잘못됐나

한 사용자가 Claude와 계획을 세우고 **"예, 자동 승인"**으로 그 계획을 승인했습니다.

그런데 그 뒤로 이어지는 편집마다 승인 요청이 떴습니다.

> Now it is asking for every single edit with "Apply / Reject" - and there are a LOT of them. So I need to babysit all the while and press "apply" [...] So I have to "sit-through" hundreds of edits for this session although I know they're all necessary and need to be approved anyways.

입력창의 모드를 **Auto mode**로 바꿔도 아무 일도 일어나지 않았습니다.

**Edit automatically**로 바꿔도 마찬가지였습니다.

화면 아래 라벨만 바뀌고 승인 요청은 계속 왔습니다.

빠져나갈 길을 찾다가 IDE diff 화면에서 **"Clear all"**이라는 세 번째 버튼을 발견했지만, 무슨 뜻인지 몰라 누르지 않았습니다.

안 누른 것이 다행이었습니다.

"Clear all"은 그 파일의 변경 선택을 전부 해제하는 버튼이라, 사용자가 원한 것과 정반대로 동작합니다.

제보는 [#393](https://github.com/Swttch/swttch/issues/393)이고, 대안 항목에는 이렇게 적혀 있습니다. *"Use CLI version."*

## 왜 그랬나

서로 다른 네 가지 결함이 하나의 경험으로 합쳐진 것입니다.

UI가 제시한 탈출구가 전부 아무 일도 하지 않았습니다.

**고른 모드가 실행 중인 CLI에 닿지 않았습니다.** `--permission-mode`는 CLI가 시작할 때 읽는 플래그라서, 대화 도중에 고른 모드는 다음 메시지에서 프로세스를 다시 띄울 때만 반영됐습니다. Claude가 작업하는 동안에는 무엇을 눌러도 바뀌는 것이 없었습니다.

**플랜 승인의 "자동 승인"이 라벨만 바꿨습니다.** 그 선택지를 고르면 화면의 입력창 모드가 *Edit automatically*로 바뀌었지만, CLI에는 모드에 대한 언급이 없는 평범한 승인만 갔습니다.

**"예, 이번 세션에서 모든 편집 허용"을 CLI에 알리지 않았습니다.** 웹뷰가 도구 이름을 기억해두고 이후 요청에 사용자 대신 조용히 답하는 방식이었습니다. CLI는 매번 계속 물었고, 질문이 답해진 것이 아니라 가려진 것이었습니다. 화면을 새로 그리면 그 기억이 사라졌고, 마침 물어본 도구 하나에만 걸렸는데 Claude는 `Edit`·`Write`·`MultiEdit`·`NotebookEdit`를 번갈아 씁니다.

**두 diff 화면 어디에도 탈출구가 없었습니다.** IDE 리뷰 바에는 `Apply`·`Reject`·`Clear all`이, 빌트인 리뷰에는 `확인`·`취소`가 있었습니다. diff를 보고 있던 사람은 진짜 답이 그 뒤의 채팅 승인 패널에 있다는 것을 알아야만 했습니다.

## 무엇이 바뀌었나

**고른 모드가 이미 실행 중인 CLI에 닿습니다.** 메뉴에서 고르든, 순환으로 넘기든, 플랜을 자동 승인으로 승인하든, 실행 중인 CLI에 모드 전환을 알립니다. 다음 턴이 아니라 지금 이 턴의 남은 편집부터 적용됩니다.

공식 경로도 그대로 살아 있고 여전히 1순위입니다. 실행 중인 CLI가 전환을 받지 않으면, 다음 메시지에서 예전과 똑같이 새 플래그로 프로세스를 다시 띄웁니다.

**"예, 이번 세션에서 모든 편집 허용"을 CLI에 전달합니다.** GUI가 질문을 가리는 것이 아니라 CLI가 스스로 묻지 않게 되므로, 화면을 새로 그려도 유지됩니다. 편집 도구 하나에서 답하면 편집 도구 전체에 걸립니다.

`Bash`에서 답하면 여전히 `Bash`에만 걸립니다. "모든 명령어 허용"은 "모든 편집 허용"보다 훨씬 큰 것을 넘기는 일이라, 조용히 넓어지지 않습니다.

**두 diff 화면 모두 탈출구를 갖습니다.**

| 화면 | 버튼 |
|---|---|
| IDE diff 리뷰 | `Allow all edits` — 왼쪽에, 이 diff를 답하는 버튼들과 떨어져서 |
| 빌트인 diff 리뷰 | `모든 편집 허용` — `확인` 옆에 |

누르면 `Apply`·`확인`과 똑같이 지금 체크된 대로 변경을 적용하면서, 그 뒤의 편집은 묻지 않게 합니다.

## 여전히 물어보는 것

명령어입니다.

`Bash`는 이번 변경과 무관하며, 명령어를 따로 허용하지 않는 한 여전히 승인이 필요합니다.

## 알려진 한계

승인 요청이 화면에 떠 있는 동안에는 입력창이 보이지 않아 모드 선택기에 손이 닿지 않습니다.

그 상황에서의 탈출구가 `Allow all edits` 버튼입니다.

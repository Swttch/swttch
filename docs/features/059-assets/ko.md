# 세션에 붙인 이미지를 한 곳에서 봅니다

> 언어: [English](./en.md) · **한국어**

## 무엇이 불편했나

대화에 스크린샷을 붙이는 일은 흔합니다. 오류 화면, 디자인 시안, 로그 캡처가 한 세션에 수십 장씩 쌓입니다.

그런데 그중 하나를 다시 보려면 방법이 하나뿐이었습니다. **그 이미지가 붙어 있던 메시지가 나올 때까지 대화를 거슬러 올라가는 것**입니다.

이미지를 눌러 크게 봐도 거기서 끝이었습니다. 바로 옆에 같이 붙인 이미지를 보려면 창을 닫고, 옆 썸네일을 찾아, 다시 눌러야 했습니다.

## 무엇이 생겼나

### 1. 방향키로 넘깁니다

이미지를 눌러 크게 본 상태에서 **←와 → 키**로 앞뒤 이미지로 넘어갑니다. **↑와 ↓** 도 같습니다. 위는 이전, 아래는 다음입니다.

화면 좌우의 화살표 버튼을 눌러도 됩니다. **Esc**를 누르면 닫힙니다.

한 장뿐일 때는 화살표와 번호가 나오지 않습니다.

### 1-1. 아래쪽 도구 모음

크게 본 화면 아래에 도구 모음이 있습니다.

| 버튼 | 하는 일 |
|---|---|
| 격자 | 이 세션의 에셋 화면으로 갑니다 |
| 확대 · 축소 | 이미지를 키우거나 줄입니다 |
| 새 탭에서 열기 | 이미지를 브라우저 새 탭에 엽니다 (브라우저에서만 보입니다) |
| 가운데 숫자 | `2 / 5`처럼 지금 몇 번째인지 |
| 복사 | 이미지를 클립보드에 담습니다 |
| 다운로드 | 이미지를 파일로 저장합니다 |

**확대 배율은 다음 이미지로 넘어가면 원래대로 돌아갑니다.** 앞 사진에 맞춰 키운 배율로 다음 사진이 잘려 보이지 않게 하기 위해서입니다.

이미지 위에서 마우스 오른쪽 버튼을 누르면 **브라우저나 IDE가 원래 주던 메뉴가 그대로 나옵니다.** 도구 모음은 그 메뉴를 대신하는 것이 아니라, 같은 일을 눈에 보이는 자리에 하나 더 둔 것입니다.

### 2. 아직 보내지 않은 첨부도 넘깁니다

입력창에 붙여두고 아직 보내지 않은 이미지도 같은 방식으로 넘겨봅니다.

이때는 **입력창에 있는 이미지끼리만** 오갑니다. 이미 보낸 이미지로 넘어가지 않습니다.

아직 대화에 들어가지 않은 것들이라, 보낸 것들과 섞어 세면 지금 무엇을 보내려는 중인지 흐려지기 때문입니다.

### 3. 에셋 화면

상단 도구 모음의 **이미지 아이콘**을 누르면 이 세션에 첨부한 이미지가 전부 나옵니다.

메시지 단위로 묶여 있고, 그때 함께 보낸 말이 제목처럼 붙습니다. 위가 오래된 것이고 아래가 최근 것이라 대화와 같은 방향으로 읽힙니다. 열면 가장 최근 쪽을 보여줍니다.

썸네일을 누르면 크게 열리고, 거기서도 방향키가 그대로 동작합니다.

> **아이콘이 안 보인다면** 도구 모음 오른쪽 끝의 `⋮`를 누르고 목록에서 **에셋**의 눈 모양 버튼을 켜주세요. 새로 추가된 항목은 처음에 숨겨져 있습니다.

## 후원자에게 열리는 것

**세션 전체를 넘겨보는 것**이 후원자 기능입니다.

| | 후원 전 | 후원자 |
|---|---|---|
| 에셋 화면 열기 | 가능 | 가능 |
| 세션의 모든 이미지 보기 | 가능 | 가능 |
| 방향키가 닿는 범위 | **그 메시지에 함께 붙인 것까지** | **세션 전체** |

후원 전에도 에셋 화면에서 이미지를 전부 볼 수 있습니다. 잠기는 것은 보는 것이 아니라, **한 장을 크게 띄운 채 세션 전체를 계속 넘겨보는 것**입니다.

그 메시지의 마지막 장에 닿으면 이 세션에 몇 장이 더 있는지 알려드립니다. 후원은 [설정 › 후원](#)에서 하실 수 있습니다.

## 무엇을 모으나

**직접 첨부한 이미지만** 모읍니다.

Claude가 작업 중에 읽은 스크린샷은 들어가지 않습니다. 에셋 화면이 "내가 보낸 메시지"를 축으로 정리되기 때문에, 사람이 보내지 않은 이미지가 섞이면 그 축이 무너집니다.

대화를 되감거나 갈래를 나눈 경우, **지금 이어지고 있는 대화의 이미지만** 보입니다. 버려진 갈래에 있던 이미지는 대화에도 안 보이므로 에셋에도 안 나옵니다.

## 느려지지 않게 한 것

이미지가 많은 세션은 통째로 열면 수십 MB입니다.

그래서 목록을 받을 때는 **이미지 내용을 빼고 위치 정보만** 받습니다. 실제 이미지는 화면에 보이려는 순간에 한 장씩 가져옵니다.

에셋 화면의 썸네일도 스크롤해서 눈에 들어올 때 불러옵니다. 한 장도 보기 전에 수십 MB를 내려받는 일이 없습니다.

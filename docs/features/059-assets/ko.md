# 세션에 붙인 에셋을 한 곳에서 봅니다

> 언어: [English](./en.md) · **한국어**

## 무엇이 불편했나

대화에 스크린샷을 붙이는 일은 흔합니다. 오류 화면, 디자인 시안, 로그 캡처가 한 세션에 수십 장씩 쌓입니다.

그런데 그중 하나를 다시 보려면 방법이 하나뿐이었습니다. **그 이미지가 붙어 있던 메시지가 나올 때까지 대화를 거슬러 올라가는 것**입니다.

이미지를 눌러 크게 봐도 거기서 끝이었습니다. 바로 옆에 같이 붙인 이미지를 보려면 창을 닫고, 옆 썸네일을 찾아, 다시 눌러야 했습니다.

## 무엇이 생겼나

### 1. 방향키로 넘깁니다

에셋을 눌러 크게 본 상태에서 **←와 → 키**로 앞뒤로 넘어갑니다. **↑와 ↓** 도 같습니다. 위는 이전, 아래는 다음입니다.

화면 좌우의 화살표 버튼을 눌러도 됩니다. **Esc**를 누르면 닫힙니다.

**화살표는 갈 곳이 없을 때도 자리를 지키고, 흐리게만 표시됩니다.** 사라지면 방금 익힌 버튼이 없어진 것처럼 보이고, 같은 화면이 열 때마다 달라 보이기 때문입니다.

### 1-1. 아래쪽 도구 모음

크게 본 화면 아래에 도구 모음이 있습니다.

| 버튼 | 하는 일 |
|---|---|
| 격자 | 이 세션의 에셋 화면으로 갑니다 |
| 확대 · 축소 | 크기를 키우거나 줄입니다 |
| 새 탭에서 열기 | 브라우저 새 탭에 엽니다 (브라우저에서만 보입니다) |
| 가운데 숫자 | `2 / 5`처럼 지금 몇 번째인지 |
| 복사 | 클립보드에 담습니다 |
| 다운로드 | 파일로 저장합니다 |

가운데 숫자는 **한 장뿐일 때도 `1 / 1`로 표시됩니다.** "더 있나?"에 대한 답이기도 하고, 장수에 따라 도구 모음의 모양이 달라지지 않게 하기 위해서입니다.

**확대 배율은 다음으로 넘어가면 원래대로 돌아갑니다.** 앞 사진에 맞춰 키운 배율로 다음 사진이 잘려 보이지 않게 하기 위해서입니다.

이미지 위에서 마우스 오른쪽 버튼을 누르면 **브라우저나 IDE가 원래 주던 메뉴가 그대로 나옵니다.** 도구 모음은 그 메뉴를 대신하는 것이 아니라, 같은 일을 눈에 보이는 자리에 하나 더 둔 것입니다.

### 2. 아직 보내지 않은 첨부도 넘깁니다

입력창에 붙여두고 아직 보내지 않은 이미지도 같은 방식으로 넘겨봅니다.

이때는 **입력창에 있는 것끼리만** 오갑니다. 이미 보낸 것으로 넘어가지 않습니다.

아직 대화에 들어가지 않은 것들이라, 보낸 것들과 섞어 세면 지금 무엇을 보내려는 중인지 흐려지기 때문입니다.

### 3. 에셋 화면

이 세션에 첨부한 것이 전부 한 화면에 나옵니다.

메시지 단위로 묶여 있고, 그때 함께 보낸 말이 제목처럼 붙습니다. 위가 오래된 것이고 아래가 최근 것이라 대화와 같은 방향으로 읽힙니다. 열면 가장 최근 쪽을 보여줍니다.

썸네일을 누르면 크게 열리고, 거기서도 방향키가 그대로 동작합니다.

여는 길은 셋입니다.

| 어디 | |
|---|---|
| 상단 도구 모음의 **에셋 아이콘** | 처음에는 숨겨져 있습니다 (아래 참조) |
| 도구 모음 오른쪽 끝 **`⋮` 메뉴** | 항상 있습니다 |
| 크게 본 화면 아래 **격자 버튼** | |

> **아이콘이 안 보이는 것이 정상입니다.** 새로 추가된 항목은 저장된 도구 모음 배치에 없어서 숨겨진 채로 들어옵니다.
>
> 에셋 화면 오른쪽 위의 **도크에 고정**을 누르면 아이콘이 도구 모음에 나옵니다. 같은 자리에서 **도크 고정 해제**로 되돌릴 수 있습니다.

## 후원자에게 열리는 것

**세션 전체를 넘겨보는 것**이 후원자 기능입니다.

| | 후원 전 | 후원자 |
|---|---|---|
| 에셋 화면 열기 | 가능 | 가능 |
| 세션의 모든 에셋 보기 | 가능 | 가능 |
| 방향키가 닿는 범위 | **그 메시지에 함께 붙인 것까지** | **세션 전체** |

후원 전에도 에셋 화면에서 전부 볼 수 있습니다. 잠기는 것은 보는 것이 아니라, **한 장을 크게 띄운 채 세션 전체를 계속 넘겨보는 것**입니다.

그래서 후원 전에는 크게 본 화면 아래에 **이 세션에 몇 장이 더 있는지** 알려드립니다. 아래 카운터가 그 메시지 안에서만 세기 때문입니다. 옆의 **전체 보기**를 누르면 에셋 화면이 열려 그 전부를 보실 수 있습니다.

흐려진 화살표에 마우스를 올리면 왜 멈췄는지 알려드리고, 거기서 후원 안내로 갈 수 있습니다.

후원은 [설정 › 후원](#)에서 하실 수 있습니다.

## 무엇을 모으나

**직접 첨부한 이미지만** 모읍니다.

Claude가 작업 중에 읽은 스크린샷은 들어가지 않습니다. 에셋 화면이 "내가 보낸 메시지"를 축으로 정리되기 때문에, 사람이 보내지 않은 것이 섞이면 그 축이 무너집니다.

대화를 되감거나 갈래를 나눈 경우, **지금 이어지고 있는 대화의 것만** 보입니다. 버려진 갈래에 있던 이미지는 대화에도 안 보이므로 에셋에도 안 나옵니다.

> 지금 담기는 것은 이미지뿐이지만, 화면과 버튼은 **에셋**이라고 부릅니다. 나중에 다른 종류가 늘어나도 이름을 바꾸지 않기 위해서입니다.

## 느려지지 않게 한 것

이미지가 많은 세션은 통째로 열면 수십 MB입니다.

그래서 목록을 받을 때는 **내용을 빼고 위치 정보만** 받습니다. 실제 이미지는 화면에 보이려는 순간에 한 장씩 가져옵니다.

에셋 화면의 썸네일도 스크롤해서 눈에 들어올 때 불러옵니다. 한 장도 보기 전에 수십 MB를 내려받는 일이 없습니다.

# 전역 설정을 바꿔도 그대로이던 문제

전역설정 이외에 프로젝트 설정에 값이 오버라이드 되어있는 항목의 경우,
1. 전역설정을 변경하게되면 프로젝트 설정에 값이 있더라도, 낙관적으로 업데이트하여 전역설정이 적용되어 버립니다.
2. 그러나 새로고침하면 다시 프로젝트 설정이 우선순위로 적용되어 로드됩니다.
3. 이는 사용자가 프로젝트 설정에 오버라이딩된 값을 의심하기보다, 전역설정이 유지되지 않는 버그로 느끼고 오해할 가능성이 큽니다.

고쳤습니다.

## 이렇게 바뀝니다

프로젝트가 이미 값을 정해둔 항목은, 전역 탭에서 이렇게 보입니다.

![프로젝트가 덮어쓴 항목은 전역 탭에서 잠깁니다](./assets/global-tab-locked.png)
*`Use Cmd+Enter To Send` 를 프로젝트가 덮어쓴 상태. 배지가 붙고 토글이 흐려집니다*

- 라벨 옆에 `P` 배지가 붙습니다.
- 오른쪽 컨트롤은 흐려져서 만질 수 없습니다.
- 배지에 마우스를 올리면 프로젝트가 덮어쓰고 있다고 알려줍니다.
- 값이 가려지지는 않습니다. 전역에 뭐라고 저장돼 있는지는 그대로 보입니다.
- 프로젝트 탭에서는 평소대로입니다. 거기서 보는 값이 실제로 쓰이는 값이니까요.

![배지에 마우스를 올리면 이유를 알려줍니다](./assets/badge-tooltip.png)

## 함께 고친 것

프로젝트 탭에서 `설정 안 함 (전역 설정 사용)` 을 골라도 전역 값이 돌아오지
않던 문제도 같이 고쳤습니다.

# UI 배율 조절

> 언어: [English](./en.md) · **한국어**
>
> 관련: [#169](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/169)

4K 모니터나 고해상도 화면에서는 기본 인터페이스가 유독 작게 느껴질 때가 있습니다. 지금까지는 전체 화면 크기를 빠르게 조절할 방법이 없었는데, 이제 브라우저나 코드 에디터에서 쓰던 그 조작 그대로 GUI 전체를 확대·축소할 수 있습니다.

![기본 배율 100%의 채팅 화면](./assets/default-100.png)

*기본 배율(100%)의 채팅 화면.*

## 조작 방법

| 동작 | 단축키 |
|------|--------|
| 확대 | `Cmd` + `+` (macOS) / `Ctrl` + `+` (Windows·Linux), 또는 수식 키를 누른 채 스크롤 업 |
| 축소 | `Cmd` + `-` (macOS) / `Ctrl` + `-` (Windows·Linux), 또는 수식 키를 누른 채 스크롤 다운 |
| 100%로 초기화 | `Cmd` + `0` (macOS) / `Ctrl` + `0` (Windows·Linux) |

수식 키는 플랫폼에 맞게 자동으로 정해집니다 — macOS는 Command, Windows·Linux는 Ctrl. 크롬이나 VS Code, IntelliJ 자체의 배율 단축키와 동일합니다.

배율은 브라우저에서 익숙한 단계를 그대로 따라갑니다: 50%, 67%, 75%, 80%, 90%, 100%, 110%, 125%, 150%, 175%, 200%, 250%, 300%. 축소했다가 다시 확대하면 항상 정확히 100%로 돌아오며, 어중간한 값에서 어긋나는 일이 없습니다.

## 조절할 때 뜨는 크롬 스타일 표시창

배율을 조절하면 화면 우측 상단에 작은 패널이 나타나 현재 퍼센트를 보여줍니다. 자체 `−` / `+` 버튼과 **초기화** 버튼도 함께 있습니다 — 크롬의 배율 컨트롤과 같은 방식입니다.

![175% 배율에서 뜬 표시창 — 퍼센트, 빼기·더하기 버튼, 초기화 버튼](./assets/zoomed-175-with-indicator.png)

*175%로 확대한 화면. 우측 상단 표시창이 키보드·휠 조작과 똑같이 반응하고, 같은 조작을 버튼으로도 제공합니다.*

알아두면 좋은 점 몇 가지입니다.

- **거슬리지 않습니다.** 표시창은 잠깐 떴다가 몇 초 뒤 조용히 사라집니다. 배율을 연달아 여러 번 조절해도 팝업이 쌓이지 않고, 하나의 표시창에서 숫자만 계속 갱신됩니다.
- **조작 중엔 사라지지 않습니다.** 마우스를 표시창 위에 올리면 자동으로 사라지는 타이머가 멈춥니다. `−`, `+`, **초기화** 버튼을 누르려는 순간 표시창이 사라지는 일은 없습니다.
- **버튼도 단축키와 똑같이 동작합니다.** `+`/`−` 버튼을 누르면 같은 단계를 따라가고, **초기화** 버튼을 누르면 바로 100%로 돌아갑니다.

![110% 배율 표시창을 가까이서 본 모습](./assets/indicator-110.png)

*표시창을 가까이서 본 모습 — 퍼센트, 빼기, 더하기, 초기화 버튼.*

## 실제로 커지는 건 무엇인가

배율은 텍스트만 키우는 게 아니라 **인터페이스 전체**를 키웁니다 — 글자, 아이콘, 여백, 테두리까지 전부. 브라우저의 페이지 배율과 같은 방식이라, 어떤 배율에서도 레이아웃이 그대로 유지되고 아이콘과 여백이 커진 글자와 안 맞아 어색해지는 일이 없습니다.

이 기능은 설정 → Appearance의 기존 **글꼴 크기** 설정과는 의도적으로 별개입니다. 글꼴 크기는 텍스트만 키우는 설정이고, 둘은 함께 적용됩니다 — 실제 텍스트 크기는 글꼴 크기 × 배율입니다. 배율만으로 원하는 느낌이 안 난다면, 글꼴 크기를 별도로 더 조절할 수 있습니다.

## 설정한 배율은 기억됩니다

조절한 배율은 자동으로 저장되어, 다음에 GUI를 열 때도 그대로 유지됩니다. 매번 다시 맞출 필요가 없습니다. 휠을 계속 돌리거나 `+`를 연타하는 등 짧은 시간에 여러 번 조작해도 저장은 한 번으로 묶여서 처리됩니다.

## 참고

- 이 기능은 브라우저의 네이티브 배율 방식을 그대로 씁니다. 그래서 어떤 배율에서도 텍스트가 흐릿한 비트맵으로 늘어나지 않고 또렷하게 유지됩니다.
- 모바일·좁은 화면에서는 사용자가 설정한 배율이 앱 자체의 모바일 확대 배율을 덮어쓰지 않고 함께 곱해져 적용됩니다.

# Settings Badges

> 언어: [English](./en.md) · **한국어**
>
> 관련: 이 기능은 `feat/auto-resume-on-limit-reset` 브랜치에 포함됩니다.

설정 화면에는 서로 성격이 다른 옵션들이 섞여 있습니다 — 어떤 것은 GUI가 여러분을 대신해 편집해 주는 실제 Claude Code CLI 설정이고, 어떤 것은 프로젝트를 후원하면 함께 열리는 추가 기능입니다. 이 차이를 한눈에 알 수 있도록, 일부 설정 행에는 제목 바로 옆에 작은 **뱃지(badge)** 가 붙습니다. 뱃지에 마우스를 올리면 그 행이 어떤 종류의 설정인지 툴팁으로 정확히 알려줍니다.

![설정 → General 화면에서 설정 행 옆에 붙은 S·C 뱃지](./assets/general-badges.png)

*설정 → General 화면. 일부 행 옆에 작은 S·C 칩이 붙어 있는 것을 볼 수 있습니다.*

## 두 가지 뱃지

현재 뱃지는 두 종류이며, 각각 작은 글자 칩입니다:

| 뱃지 | 글자 | 색 | 의미 | 툴팁 |
|------|:----:|-----|------|------|
| **Sponsor** | `S` | 파란색 | 이 행은 **후원 전용 기능**에 속함 | *Sponsor-only feature* |
| **Claude Code native** | `C` | 주황색 | 이 행은 **실제 Claude Code CLI 설정**을 편집함 | *Claude Code native setting* |

뱃지는 일부러 작고 눈에 거슬리지 않게 만들었습니다 — 배너가 아니라 조용한 신호입니다. 뱃지를 직접 조작할 필요는 전혀 없고, "지금 내가 보고 있는 게 정확히 뭐지?" 하는 궁금증이 생겼을 때 그 답을 주기 위해 존재합니다.

## Sponsor 뱃지 (S)

**S** 뱃지는 **후원 전용 기능**에 속하는 설정을 표시합니다. 이 뱃지가 보이면, 그 행이 프로젝트를 후원했을 때 열리는 추가 기능 중 하나라는 뜻입니다.

![Sponsor 뱃지 툴팁 "Sponsor-only feature"](./assets/sponsor-tooltip.png)

*파란색 **S** 뱃지에 마우스를 올리면 "Sponsor-only feature"가 표시됩니다.*

Claude Code with GUI는 계속 무료로 사용할 수 있으며, 후원은 이 독립적인 JetBrains 우선 프로젝트가 계속 나아가게 하는 힘입니다. 프로젝트를 후원하면 이 뱃지가 붙은 모든 후원 전용 기능은 물론, 앞으로 추가될 기능들까지 자동으로 열립니다. 그러니 **S** 뱃지는 친절한 안내표라고 생각하시면 됩니다 — 후원과 함께 따라오는 혜택들을, 혹시 원하실 경우를 위해 짚어 주는 것입니다. 원치 않으셔도 전혀 문제 없습니다 — 핵심 기능은 무료이고, 앞으로도 무료입니다.

예를 들어 설정 → General의 **Auto-resume on usage limit**(사용량 한도 도달 시 자동 재개) 행에 **S** 뱃지가 붙습니다.

## Claude Code native 뱃지 (C)

**C** 뱃지는 그 설정이 **실제 Claude Code CLI 설정**임을 표시합니다 — GUI는 그저 그것을 더 편하게 편집할 수 있도록 해줄 뿐입니다. 이는 앱 안에만 존재하는 GUI 전용 편의 설정과는 다릅니다. **C** 뱃지가 붙은 옵션을 바꾸면, 여러분은 `claude` 명령줄 도구 자체가 이해하는 값을 바꾸는 것입니다.

![Claude Code native 뱃지 툴팁과 문서 링크 아이콘](./assets/claude-native-tooltip.png)

*주황색 **C** 뱃지에 마우스를 올리면 "Claude Code native setting"이 표시되고, 해당 설정의 공식 문서를 여는 링크 아이콘이 함께 나타납니다.*

설정이 공식 Claude Code 설정 키에 대응할 경우, 툴팁에 작은 외부 링크 아이콘이 함께 표시됩니다. 이 아이콘을 클릭하면 그 키에 대한 **공식 Claude Code 문서**가 새 브라우저 탭에서 열립니다 — 출처에서 직접 나온 정확한 설명을 한 번의 클릭으로 읽을 수 있습니다. 이 경우 툴팁에 클릭 가능한 링크가 있으므로 툴팁이 상호작용형으로 동작합니다 — 마우스를 뱃지에서 링크 위로 옮겨도 툴팁이 사라지지 않습니다.

예를 들어 설정 → General의 **fileSuggestion** 행에 **C** 뱃지가 붙으며, 그 툴팁은 해당 설정의 공식 문서 페이지로 곧바로 연결됩니다.

## 어디서 볼 수 있나요

뱃지는 이 신호가 필요한 설정 행이라면 어디든 나타납니다 — 가장 눈에 잘 띄는 곳은 **설정 → General**이며, 그 외 설정 화면들에서도 CLI 네이티브 옵션 옆에 붙습니다. 일부러 찾아다닐 필요는 없고, 해당하는 행에 자연스럽게 나타납니다.

## 참고

- 뱃지는 **정보 표시용**입니다. 컨트롤의 동작을 바꾸지 않으며, 그저 어떤 종류의 설정인지 라벨을 달아줄 뿐입니다.
- 한 행은 한 종류에만 해당하므로, 설정 하나당 뱃지는 최대 하나만 보입니다.
- **C** 뱃지의 문서 링크는 항상 공식 Claude Code 문서를 **새 탭**에서 엽니다. 그래서 앱에서 보던 위치를 잃지 않습니다.

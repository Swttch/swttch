# 기능 문서 색인 (Feature Docs Index)

이 폴더는 사용자를 독자로 한 **기능 설명서**들을 모아둔다. 작성 규칙은 [docs/CLAUDE.md](../CLAUDE.md)를 따른다.

각 기능은 `NNN-feature_name/` 폴더로 관리하며, 폴더 안에 언어별 번역본(`en.md`, `ko.md`, …)을 둔다.

- [Context usage in chat](./011-context_command_in_chat/en.md) — `/context` 슬래시 명령을 GUI 채팅에서 정상 실행하고, 터미널 TUI처럼 컬러 격자 기반 컨텍스트 사용량 카드로 렌더링 ([#196](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/196), [#198](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/198))
- [Editor context follows the focused panel](./012-editor_context_focused_panel/en.md) — 여러 Claude 패널/탭을 열어도 파일 뱃지와 `Alt+K` 멘션이 마지막으로 포커스한 패널로만 가도록 라우팅. 새 탭/브라우저의 페어링 세션 재사용(403 방지), 툴윈도우 `Alt+K` 새탭 방지, 마지막 포커스가 브라우저면 IDE 미개입 포함 ([#180](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/180), [#199](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/199), [#205](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/205), [#207](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/207))
- [Adjustable chat line spacing](./014-line_spacing/en.md) — 채팅 메시지 본문 텍스트(문단·리스트·헤딩·인용·표)의 줄 간격을 설정 → Appearance → Theme의 글꼴 크기 아래 "줄 간격" 숫자 입력(0.5~10, 0.1 단위, 기본 1.6)으로 조절. 값이 없으면 기존 1.6로 폴백해 회귀 없음, 코드 블록·인라인 코드는 자체 고정 간격 유지 ([#218](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/218), [#221](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/221))
- [Clickable jump-to-line file references in chat](./013-clickable_file_references/en.md) — Claude 답변 속 파일 참조를 클릭하면 IDE에서 해당 라인(·컬럼)으로 열리게 하는 기능. Markdown 파일 링크, 문장 속 평문 `path:line`/`:line:col`/`#L…` 표기, `@` 멘션 칩의 라인 이동을 포함. 코드/기존 링크/URL·슬래시 없는 토큰·라인 없는 언급은 보수적으로 제외 ([#183](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/183), [#209](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/209), [#210](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/210))
- ["Open files with": detect and launch your editor of choice](./014-open_files_with/en.md) — 채팅에서 클릭한 파일 참조를 사용자가 고른 에디터/IDE(JetBrains 제품군·VS Code·Cursor·Xcode·Zed 등)로 여는 설정. GitHub Desktop 방식을 참고해 macOS 번들 ID(Spotlight 꺼져도 동작)·Windows 레지스트리·Linux PATH로 감지하고, 시스템 기본·직접 지정(경로+`%TARGET_PATH%` 인자)을 지원. 설정을 CLI 탭으로 이동, 터미널 감지도 같은 엔진으로 통합 리팩토링, 설정 저장을 원자화 ([#213](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/213), [#214](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/214))
- [@ file mentions find submodule files, and honor the fileSuggestion setting](./015-file_mention_submodules_and_filesuggestion/en.md) — `@` 파일 멘션이 git 서브모듈 내부 파일을 찾고(내장 인덱스를 `git ls-files --recurse-submodules`와 `--others` 2회 병합으로 개선, `.gitignore` 존중 유지), CLI의 `fileSuggestion` 설정을 존중해 `@` 인덱스 생성 명령을 사용자가 지정할 수 있게 함(설정 → General, `settings.json`과 동일 값·query를 stdin JSON으로 전달·실패 시 내장 인덱스로 폴백) ([#201](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/201), [#223](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/223))
- [@ file mentions rank with fuzzy subsequence matching (IntelliJ-style)](./016-mention_fuzzy_search/en.md) — `@` 파일 멘션 목록을 연속 부분 문자열 필터에서 IntelliJ Search Everywhere / CamelHump 방식의 퍼지(부분수열) 랭킹으로 교체해 `@bcva`가 `business-case-validation-architecture.md`를 찾게 하고(단어 경계·연속·basename 보너스로 순위, 흩어진 매칭 감점), 매칭된 글자를 드롭다운에서 강조(백엔드가 `matchIndices`를 반환→웹뷰가 원본 그대로 전달→`renderHighlightedPath`가 강조) ([#170](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/170), [#224](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/224))
- [Settings Badges](./017-settings_badges/en.md) — 설정 화면의 각 항목 옆에 작은 뱃지를 달아 그 설정의 "종류"를 한눈에 보여주는 기능. 파란 **S**(Sponsor) 뱃지는 후원자를 위한 기능임을, 주황 **C**(Claude Code native) 뱃지는 실제 Claude Code CLI 설정임을 표시하고, 뱃지에 호버하면 툴팁(그리고 C 뱃지는 공식 문서로 가는 링크)을 보여준다 (`feat/auto-resume-on-limit-reset` 브랜치)
- [Scheduled Messages](./018-scheduled_messages/en.md) — 채팅 메시지를 나중에 보내도록 예약하는 Slack식 "send later" 기능(후원자를 위한 기능). 슬래시 패널 → Context → "Schedule a message…"로 예약 팝오버를 열고(컴포저 초안 자동 채움, 메인 컴포저와 같은 리치 에디터), 프리셋·기간 지정·정확한 시각으로 발송 시각을 고른다. 발송 시각이 되면 사람이 직접 보낸 것과 동일한 경로로 한 탭에서 전송하며, 상단바 시계 버튼→패널에서 세션별 예약을 실시간 카운트다운과 함께 조회·수정·취소(CRUD)한다 (`feat/auto-resume-on-limit-reset` 브랜치)
- [Auto-resume on usage-limit reset](./019-auto_resume_on_limit/en.md) — 사용량/세션 한도에 도달했을 때 사용량이 리셋되는 순간 대화를 자동으로 이어가는 기능(후원자를 위한 기능). Scheduled Messages 엔진 위에 만들어져 리셋 시각에 "continue"를 예약하고, 백엔드 게이트가 전송 직전 사용량을 재확인(5초 폴링·최대 10분, 네트워크 오류 시 사람이 읽을 수 있는 사유로 중단)해 실제 충전된 뒤에만 발사한다. 한도 배너의 예약/즉시 재개 버튼, 설정 → General의 기본값 토글(세션별 오버라이드 가능)을 제공하며, 리셋 시각은 CLI 한도 안내 문구에서 직접 파싱(공식/미문서 API 비의존) (`feat/auto-resume-on-limit-reset` 브랜치)
- [Models you connect yourself now show by their own name](./021-custom_model_catalog_display/en.md) — Opus/Sonnet/Haiku 자리에 직접 연결한 모델(`ANTHROPIC_DEFAULT_*_MODEL`)을 쓸 때, 대화를 시작하면 입력창 아래 표시와 모델 선택 패널이 **Default** 로 되돌아가고 그 자리에 들어간 긴 문장이 줄을 두 줄로 무너뜨리던 문제를 수정. 근본 원인은 이름을 못 알아본 것이 아니라 **"못 알아봤다"를 "기본값이다"로 단정**해 사용자 선택을 버린 것 — 이제 식별에 실패하면 폴백하지 않고 **기존 선택을 그대로 유지**한다(다음 요청도 그 모델로 나감). 이름 형태에 의존하지 않는 규칙이라 GLM 외 임의 커스텀 모델에도 대응. 부수적으로 식별 성공률도 높임(설명의 `Custom Haiku model` 활용, 접미사·대소문자 흡수)하고, 끝내 모르는 모델은 Default 인 척하지 않고 원본 값 그대로 표시. 입력창 아래 줄은 좁은 폭에서도 한 줄 유지 + 말줄임(권한·사용량 표시 포함) ([#217](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/217), [#202](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/202))
- [@ file mentions now work inside slash commands](./020-mention_inside_slash_command/en.md) — 슬래시 명령을 입력하는 중에 `@` 를 쳐도 파일 선택 목록이 뜨지 않던 문제를 수정. 슬래시 패널과 파일 목록이 입력창 위 같은 자리를 공유하는데 판단 기준이 "줄이 `/` 로 시작하나"뿐이라, 검색이 끝난 목록이 패널에 계속 가려져 있었다(바깥을 클릭하면 잠깐 보였다가 다음 글자에 다시 가려짐). 기준을 "커서가 `@토큰` 안에 있나"로 바꿔 두 기능이 자리를 나눠 쓰게 했고, 파일 선택 후 슬래시 패널 복귀·커서 되돌림 시 목록 재표시·이메일 주소 오작동 방지를 함께 정리. 스킬 전용 문제가 아니라 모든 슬래시 명령에 해당 ([#236](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/236))

# 기능 문서 색인 (Feature Docs Index)

이 폴더는 사용자를 독자로 한 **기능 설명서**들을 모아둔다. 작성 규칙은 [docs/CLAUDE.md](../CLAUDE.md)를 따른다.

각 기능은 `NNN-feature_name/` 폴더로 관리하며, 폴더 안에 언어별 번역본(`en.md`, `ko.md`, …)을 둔다.

Scheduled Messages 엔진 위에 만들어져 리셋 시각에 "continue"를 예약하고, 백엔드 게이트가 전송 직전 사용량을 재확인(5초 폴링·최대 10분, 네트워크 오류 시 사람이 읽을 수 있는 사유로 중단)해 실제 충전된 뒤에만 발사한다. 한도 배너의 예약/즉시 재개 버튼, 설정 → General의 기본값 토글(세션별 오버라이드 가능)을 제공하며, 리셋 시각은 CLI 한도 안내 문구에서 직접 파싱(공식/미문서 API 비의존) (`feat/auto-resume-on-limit-reset` 브랜치)
- [Models you connect yourself now show by their own name](./021-custom_model_catalog_display/en.md) — Opus/Sonnet/Haiku 자리에 직접 연결한 모델(`ANTHROPIC_DEFAULT_*_MODEL`)을 쓸 때, 대화를 시작하면 입력창 아래 표시와 모델 선택 패널이 **Default** 로 되돌아가고 그 자리에 들어간 긴 문장이 줄을 두 줄로 무너뜨리던 문제를 수정. 근본 원인은 이름을 못 알아본 것이 아니라 **"못 알아봤다"를 "기본값이다"로 단정**해 사용자 선택을 버린 것 — 이제 식별에 실패하면 폴백하지 않고 **기존 선택을 그대로 유지**한다(다음 요청도 그 모델로 나감). 이름 형태에 의존하지 않는 규칙이라 GLM 외 임의 커스텀 모델에도 대응. 부수적으로 식별 성공률도 높임(설명의 `Custom Haiku model` 활용, 접미사·대소문자 흡수)하고, 끝내 모르는 모델은 Default 인 척하지 않고 원본 값 그대로 표시. 입력창 아래 줄은 좁은 폭에서도 한 줄 유지 + 말줄임(권한·사용량 표시 포함) ([#217](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/217), [#202](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/202))
- [@ file mentions now work inside slash commands](./020-mention_inside_slash_command/en.md) — 슬래시 명령을 입력하는 중에 `@` 를 쳐도 파일 선택 목록이 뜨지 않던 문제를 수정. 슬래시 패널과 파일 목록이 입력창 위 같은 자리를 공유하는데 판단 기준이 "줄이 `/` 로 시작하나"뿐이라, 검색이 끝난 목록이 패널에 계속 가려져 있었다(바깥을 클릭하면 잠깐 보였다가 다음 글자에 다시 가려짐). 기준을 "커서가 `@토큰` 안에 있나"로 바꿔 두 기능이 자리를 나눠 쓰게 했고, 파일 선택 후 슬래시 패널 복귀·커서 되돌림 시 목록 재표시·이메일 주소 오작동 방지를 함께 정리. 스킬 전용 문제가 아니라 모든 슬래시 명령에 해당 ([#236](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/236))

- [Typing `/` mid-sentence opens the command panel](./022-slash_panel_after_text/en.md) — 문장을 쓰던 중에 `/` 를 치면 명령 패널이 아예 뜨지 않아 스킬·CLI 명령을 꺼낼 수 없던 문제를 수정. 패널이 "입력창 전체가 `/` 로 시작하나" 하나로만 열릴지를 판단했기 때문으로, 기준을 `@` 멘션과 같은 모양(줄 맨 앞이나 공백 뒤의 `/` + 커서가 그 토큰 안)으로 맞췄다(토큰 안에 `/` 가 또 있으면 경로로 보고 무시). 같은 기준에서 비롯된 두 번째 증상도 함께 정리 — 쓰던 문장 뒤에서 항목을 고르면 실행·전송하지 않고 이름만 채워 넣어(커서는 이름 뒤 공백 다음) 앞서 쓴 문장이 사라지지 않게 했고, 빈 입력창에서 고르면 지금까지처럼 즉시 실행 ([#244](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/244))
- [The view stays where you put it while you read](./023-auto_scroll_stays_put/en.md) — 답변이 흘러나오는 동안 위로 올려 읽고 있어도 화면이 자꾸 바닥으로 끌려 내려가던 문제를 수정. 원인은 두 가지였다. 첫째, "사용자가 새 메시지를 보냈나"를 대화 기록의 종류만으로 판단했는데 **도구 실행 결과도 사용자 메시지와 같은 종류로 기록**되기 때문에 파일을 읽거나 명령을 실행할 때마다 아래 따라가기가 다시 켜졌다(실제 대화 40개·26,941건 기준 384번 보냈는데 5,031번 끌려 내려감 — 92%가 불필요). 이제 사람이 직접 입력한 것(글·붙여넣은 이미지)만 전송으로 세고, 도구 결과·압축 요약 등 CLI가 스스로 기록한 항목은 제외한다. 둘째, **자동 스크롤 재개 거리** 설정이 "다시 따라가기" 판단에만 쓰이고 "멈추기"는 설정과 무관한 2픽셀 기준이 따로 쥐고 있어, 살짝만 올려도 자동 스크롤은 꺼졌는데 "맨 아래로 스크롤" 버튼은 안 뜨는 구간(기본값에서 0~80px)이 있었다. 이제 설정값 하나가 멈춤·재개 양쪽의 유일한 경계이며, 자동 스크롤이 꺼진 상태와 버튼이 보이는 상태가 항상 일치한다. 옛 동작을 적고 있던 설정 설명 문구도 12개 언어 전부 수정 ([#206](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/206))
- [UI Zoom](./024-ui_zoom/en.md) — `Cmd`/`Ctrl` + `+`/`-`/`0`, 또는 수식 키를 누른 채 스크롤로 GUI 전체(텍스트·아이콘·여백·테두리)를 확대·축소하는 기능. 브라우저와 같은 배율 단계(50%~300%)를 밟아 축소 후 재확대 시 정확히 원래 값으로 복귀하고, 조절 중엔 크롬 스타일 표시창이 우측 상단에 떠 실시간 퍼센트와 `−`/`+`/초기화 버튼을 제공(호버 시 유지, 반복 조작해도 팝업이 쌓이지 않고 숫자만 갱신). 기존 글꼴 크기 설정과는 독립적으로 곱해져 적용되며, 설정값은 자동 저장되어 다음 실행에도 유지 ([#169](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/169))
- [Collapsible prompt panels & clickable "Esc to cancel"](./025-collapsible_prompt_panels/en.md) — Claude가 되묻는 세 패널(도구 권한 확인·계획 승인·선택지 질문)을 우측 상단 버튼으로 한 줄 바까지 접어두고 다시 펼치는 기능. 좁은 화면에서 판단 근거가 될 대화 내용이 패널에 가려지던 문제를 해소한다 — 접기는 취소가 아니라 대기 유지이며, 접힌 바에 패널 제목이 남아 무엇이 대기 중인지 알 수 있고, 접은 동안에는 숫자 키 선택이 차단되어(Esc 취소는 유지) 뒤 내용을 읽다 실수로 승인되지 않는다. 접힘은 그 패널 하나에만 적용되어 다음 질문은 항상 펼쳐진 채 뜬다. 더불어 예전부터 안내문일 뿐이던 "취소하려면 Esc" 문구 자체를 클릭하면 Esc와 동일하게 취소되도록 해, 키보드가 없는 모바일·태블릿 접속에서도 안내대로 취소할 수 있게 했다 ([#248](https://github.com/yhk1038/claude-code-gui-jetbrains/pull/248))
- [Pick which header icons stay out, and in what order](./026-customizable_header_dock/en.md) — 채팅 상단바 오른쪽에 기능마다 하나씩 쌓이던 아이콘 여섯 개를 더보기(⋮) 메뉴 하나로 정리하고, 자주 쓰는 것만 골라 ⋮ 왼쪽 "도크"로 꺼내 쓰게 한 기능. 아이콘이 늘어날 때마다 같은 폭을 나눠 쓰는 왼쪽 세션 제목이 먼저 잘려나갔고, 여섯 개 중 상당수는 사람마다 쓰임새가 갈리는데 모두에게 똑같이 자리를 차지했다. 이제 기본값은 ⋮ 하나뿐이며, ⋮를 열면 별도 편집 모드 없이 여섯 항목이 하나의 목록으로 곧바로 보인다(Notion의 속성 보이기/숨기기처럼 눈 아이콘으로 도크 노출을 토글 — 빈 "도크에 포함" 섹션이 어색해 보이던 2섹션 드래그 방식 대신 채택). 각 행은 손잡이·눈 아이콘·행 자체 세 자리로 갈라 손잡이를 잡아야만 순서 변경 드래그가 시작되고(끌던 중 `Esc`로 취소), 눈 아이콘을 눌러야만 도크 노출이 바뀌며, 그 사이 행 자체를 누르면 기능이 바로 실행된다. 도크 아이콘 순서는 이 목록의 순서를 그대로 따른다(별도 도크 순서 없음). 배치는 전역으로 저장되어 프로젝트를 옮겨도 같은 자리에 있다 — 도크는 손이 기억하는 도구 모음이기 때문. 도크에 꺼낸 기능도 메뉴에서 사라지지 않아, 도크·메뉴 어느 쪽에서 눌러도 동작이 같다. 각 행 우측에는 도크 아이콘이 보여주는 것과 동일한 실시간 상태가 뜬다 — 사용량은 배터리+퍼센트(미설정 시 "설정" 안내), 예약된 메시지·백그라운드 작업은 활성 시 아이콘 색이 바뀌고 우측엔 0건이 아닐 때만 숫자 배지, 원격 터널은 아이콘이 활성 시 초록으로 바뀌고 우측엔 활성일 때만 초록 "활성" 텍스트, 설정·새 탭은 보여줄 상태가 없어 해당 없음. 계정 전환은 실행 동작이 아니라 고르는 목록이라 이 정리 대상에서 빠지고, 예전처럼 ⋮ 오른쪽에 별도 상시 아이콘으로 남는다. 새 기능이 추가되면 목록 맨 아래에 도크 미노출 상태로 자동 추가되어 이전 배치가 신기능을 가리지 않는다 (자체 기획)

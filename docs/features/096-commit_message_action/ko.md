# Commit 도구 창에서 커밋 메시지 만들기

> Language: [English](./en.md) · **한국어**

> 관련: [#426](https://github.com/Swttch/swttch/issues/426)

## 이제 보이는 것

Commit 도구 창의 `Vcs.MessageActionGroup`에 Claude 버튼이 있습니다. Git 변경
항목을 하나 이상 선택하고 버튼을 누르면, 플러그인은 Git 작업 디렉터리와 선택한
경로만 로컬 백엔드로 보냅니다. 백엔드는 선택한 diff와 최근 커밋 20개의 제목을
모아 Claude Code에게 커밋 메시지를 요청하고, 결과를 Commit message 필드에
넣습니다.

프롬프트는 최근 커밋들의 언어·스타일·scope 규칙이 일관되면 그것을 따르라고
합니다. 일관하지 않으면 Conventional Commits를 씁니다. 첫 줄은 72자 미만을
유지하고, 여러 논리적 변경이 있을 때만 본문을 붙입니다. 본문 한 줄은 하나의
완전한 논리적 항목이나 문장으로 쓰고, 고정 폭에 맞추려고 문장 중간에서
줄바꿈하지 않습니다.

Claude Code가 생성하는 동안에는 같은 도구 모음 버튼이 **Stop**으로 바뀝니다.
클릭하면 로컬 요청 연결을 끊고 1회성 CLI 프로세스를 종료합니다. 취소해도
기존 Commit message 필드 내용은 그대로 유지됩니다.

## 필요한 것

| 필요한 것 | 내용 |
| --- | --- |
| Git 변경 항목 | 포함된 변경 항목 또는 포함된 비버전 파일이 하나 이상 있어야 합니다 |
| 하나의 Git 루트 | 선택한 파일이 모두 같은 Git 저장소에 있어야 합니다 |
| 지원되는 프로젝트 루트 | 저장소 루트가 IDE 프로젝트와 같거나 그 안에 있어야 합니다 |
| Claude Code | CLI가 설치·인증되어 있어야 합니다 |

workflow, 메시지 필드, 유효한 선택 항목, 백엔드 프로젝트 루트 중 하나라도
없으면 버튼은 사라지지 않고 경고를 보여 줍니다.

## 프라이버시와 한계

요청은 로컬 백엔드에 머물고, 선택한 경로와 해당 Git diff를 포함합니다. diff는
120,000자에서 잘리고, 요청 하나는 최대 500개 경로를 받습니다. Claude Code에는
120초 타임아웃으로 세션을 남기지 않는 1회성 요청을 보냅니다. restricted CLI
모드는 Anthropic 공식 API 엔드포인트에서만 사용하며, 다른
`ANTHROPIC_BASE_URL`이 설정된 경우 Anthropic 호환 게이트웨이와의 호환성을 위해
생략합니다.

# 저장소 안에 프로젝트가 여러 개여도, 한 화면에서 오갑니다

한 저장소 안에 `packages/` 로 하위 프로젝트를 여러 개 두고 쓰는 경우가 있습니다.

지금까지 세션 드롭다운은 **바로 아래 한 단계만** 보여줬습니다. `packages/claude-code-battery` 처럼 두 단계 아래에 있는 프로젝트는 목록에 아예 뜨지 않아서, "전체 찾아보기"로 돌아가야 했습니다.

이번에 세 가지가 달라졌습니다.

## 아무리 깊어도 트리에 나옵니다

깊이 제한이 없어졌습니다. 두 단계든 일곱 단계든 전부 나옵니다.

중간에 낀 폴더는 세션을 돌린 적이 없어도 구조를 보여주기 위해 함께 그립니다. 아래 `packages` 가 그런 줄입니다 — **흐린 색에 빈 폴더 아이콘**이고, 클릭되지 않습니다.

가지 기호(`├─`) 대신 폴더 아이콘과 접기 화살표를 씁니다. JetBrains IDE의 프로젝트 트리와 같은 방식입니다.

- **꽉 찬 폴더** — 실제로 세션이 있는 프로젝트. 오른쪽에 세션 수가 붙습니다
- **빈 폴더 (흐림)** — 경로를 잇기 위한 줄. 클릭 안 됨

화살표로 접었다 펼 수 있고, 처음엔 전부 펼쳐진 상태입니다. 접은 상태는 기억하지 않습니다 — 지금 트리를 훑어보기 위한 것이지 설정이 아니기 때문입니다.

목록이 길어지면 패널 가로폭도 따라 늘어납니다. 화면 폭까지가 한계이고, 모바일에서는 처음부터 화면 전체를 씁니다.

## 하위 프로젝트의 대화까지 한 목록에서

드롭다운 위쪽의 **"하위 프로젝트 포함"** 을 켜면, 지금 보고 있는 위치 아래의 모든 프로젝트 대화가 한 목록으로 합쳐집니다.

합쳐진 목록에서는 각 줄에 **어느 프로젝트의 대화인지** 제목 위에 함께 표시됩니다.

이 설정은 기억됩니다. 한 번 켜두면 다음에도 켜진 채로 시작합니다.

### 하위 대화를 열어도, 보던 자리는 그대로입니다

여기가 중요한 부분입니다.

`packages/active-cli-sdk` 의 대화를 열어도 **드롭다운은 여전히 저장소 루트를 기준으로 보여줍니다.** 방금 연 대화가 있는 줄에 선택 표시만 옮겨갈 뿐입니다.

그래서 넓게 보던 시야를 잃지 않고 다음 대화로 넘어갈 수 있습니다. 대화 자체는 원래 있던 프로젝트 폴더에서 정상적으로 실행됩니다.

`/clear` 로 새 대화를 시작해도 마찬가지입니다.

## 검색에 프로젝트 이름도 걸립니다

세션 검색창에 프로젝트 이름을 쳐도 찾아집니다. `active` 나 `packages/` 처럼 일부만 입력해도 됩니다.

제목·세션 ID와 똑같이 취급하므로, "하위 프로젝트 포함"을 켜지 않았을 때도 동작합니다.

## 왼쪽 세션 패널도 같습니다

위 내용은 상단 세션 드롭다운과 **왼쪽 사이드 세션 패널 양쪽에 그대로 적용**됩니다. 두 화면이 같은 목록을 공유합니다.

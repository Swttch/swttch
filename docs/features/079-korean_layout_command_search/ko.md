# 한글 자판 상태로 친 슬래시 명령

> 언어: [English](./en.md) · **한국어**

키보드가 한글 자판인 채로 슬래시 명령을 치기 시작해도 이제 명령 목록이 그 명령을 찾아 줍니다. `/rename`을 그렇게 치면 `/ㄱㄷㅜㅁㅡㄷ`이 되는데, 더 이상 자판을 바꿔서 처음부터 다시 칠 필요가 없습니다.

## 무엇을 하는가

한글 자음과 모음은 모두 영문자와 같은 키에 놓여 있습니다. ㄱ은 **R** 키, ㄷ은 **E** 키, ㅜ는 **N** 키입니다. 명령 목록은 입력한 글자를 그 키로 되돌린 것도 함께 검색합니다.

`/ㄱㄷ`을 치면 `/re`를 쳤을 때와 같은 목록이 나옵니다. `/recap`, `/reload-plugins`, `/reload-skills`, `/rename`이 보이고, 맞은 글자는 굵게 표시됩니다.

![`/ㄱㄷ`을 입력한 채팅 입력창. 위의 명령 목록에 "Context" 아래 "Resume conversation"과 "Schedule a message...", "Model" 아래 "Toggle auto-resume on limit", "Slash Commands" 아래 "/recap", "/reload-plugins", "/reload-skills", "/rename"이 있고, 각 이름에서 "re"가 굵게 표시됩니다.](./assets/korean-layout-search.png)

글자가 낱개로 남아 있든, 입력기가 이미 음절로 묶었든 똑같이 동작합니다. `/ㄱㄷㅜㅁㅡㄷ`과 `/ㄱ두믇` 모두 `/rename`을 찾습니다.

## 그렇게 친 명령을 실행하면

이름을 한글 글자로 쓴 채로, 뒤에 인자를 붙여서 명령을 고르거나 Enter를 누르면 됩니다.

`/ㄱㄷㅜㅁㅡㄷ Release checklist`

이 줄은 Claude Code에 `/rename Release checklist`로 전달됩니다. 이 처리가 없으면 인자가 사라지거나 명령을 알아보지 못했을 것입니다.

이름 뒤의 글자를 읽는 모든 명령이 대상입니다. CLI로 그대로 보내는 명령, `/btw`처럼 이 앱이 직접 실행하는 명령, 그리고 `/model`입니다.

## 제목 미리보기도 동작합니다

[`/rename ` 뒤의 제목 미리보기](../078-rename_session_names/ko.md)는 `/ㄱㄷㅜㅁㅡㄷ `을 쳤을 때도 나옵니다.

## 한글 그대로의 검색도 계속됩니다

입력한 글자 그대로의 검색은 멈추지 않습니다. 이름이 한글인 항목, 예를 들어 모델 전환의 한글 이름은 `/모델`처럼 그 한글 단어로 계속 찾아집니다. 입력한 글자를 **그대로도, 키로 바꿔서도** 검색하고 둘 중 하나라도 맞으면 보여 줍니다.

## 하지 않는 것

- **슬래시 명령만 대상입니다.** `@` 파일 참조와 `!!` 프롬프트 검색은 그대로입니다.
- **표준 한글 자판(두벌식)만** 변환합니다. 세벌식 같은 다른 자판은 변환하지 않습니다.
- **글자를 조합하는 중에는 목록이 한 음절 늦습니다.** 한글 입력기는 음절이 끝나기 전에는 입력창의 글자를 앱에 넘기지 않기 때문에, 목록은 지금 조합 중인 음절 바로 앞까지만 반영합니다. 다음 글자나 공백을 치는 순간 따라잡습니다. 영어 입력에는 이런 지연이 없습니다.
- **번역은 하지 않습니다.** 한글 글자를 그 글자가 놓인 키로 바꿀 뿐 단어의 뜻을 옮기지 않습니다.
- 어떤 명령과도 맞지 않은 줄(글자가 아무것에도 맞지 않는 경우 등)을 보낼 때는 줄을 그대로 보냅니다.

# 빈 말풍선이 사라지고, `$` 가 들어간 문장이 온전히 보입니다

> 언어: [English](./en.md) · **한국어**
>
> 관련: [#232](https://github.com/yhk1038/claude-code-gui-jetbrains/issues/232)

## 제보

한 사용자가 대화 중간에 **내용이 없는 빈 말풍선**이 뜬다고 알려주셨습니다. 테두리와
배경만 있고 안은 비어 있는 작은 조각이, 어떤 때는 화면을 채울 만큼 줄줄이 이어졌습니다.

제보자는 원인까지 짚어주셨습니다. 어시스턴트 답변 쪽에는 "내용이 비면 그리지 않는다"는
장치가 있는데 사용자 메시지 쪽에는 그것이 없다는 지적이었고, 그 지적이 정확했습니다.

## 실제로 벌어지던 일

말풍선을 그리는 상자는 **안에 무엇이 들어오든 상관없이 테두리와 배경을 먼저 그립니다.**
그래서 표시할 글자가 하나도 없는 메시지가 오면, 좌우 여백만 남은 **가로 18px·세로 9px**
짜리 빈 조각이 그대로 화면에 남았습니다.

이런 메시지는 특별한 사고가 아니라 평소에도 오갑니다.

- Claude Code가 내부적으로 붙이는 안내표(`<system-reminder>`)만 담긴 메시지 — 표를
  걷어내면 남는 글자가 없습니다.
- 열어둔 파일 정보만 담긴 메시지 — 그 정보는 아래쪽 파일 칩으로 따로 나가고, 본문은
  비게 됩니다.
- 내용이 아예 비어 있는 채로 도착한 메시지.

## 무엇이 바뀌었나

**보여줄 것이 하나도 없으면 말풍선을 그리지 않습니다.** 글자, 이미지, 파일 칩 중 어느
하나라도 있으면 지금까지처럼 보이고, 전부 없을 때만 조용히 넘어갑니다. 어시스턴트 답변
쪽이 원래 하던 방식과 같아져, 이제 양쪽이 같은 기준으로 움직입니다.

한 가지는 일부러 남겨두었습니다. **도구 실행 결과는 본문이 비어 있어도 지우지 않습니다.**
그 메시지가 비어 보이는 이유는 내용이 없어서가 아니라 바로 위 도구 카드 안으로 합쳐지기
때문인데, 아직 불러오지 않은 이전 대화에 그 카드가 있으면 합쳐질 곳이 없습니다. 이때
지워버리면 도구가 내놓은 결과가 소리 없이 사라집니다. 그래서 "글자가 비었나"가 아니라
**"정말 보여줄 것이 없나"**를 기준으로 삼았습니다.

## 함께 고친 것 ①: `$` 가 들어간 문장이 깨지던 문제

빈 말풍선을 조사하다 더 큰 문제를 찾았습니다.

`$` 기호 두 개가 한 문장에 들어가면, 그 사이를 **수학 수식으로 착각**했습니다. 셸 변수
(`$VAR`)나 가격을 이야기하는 평범한 문장이 대상이 됐습니다. 그러면 `$` 가 사라지고,
사이에 낀 부분이 수식으로 다시 그려지고, **주변 문장이 화면에 여러 번 겹쳐 나왔습니다.**

실제로 이렇게 보였습니다.

```
쓴 것 : 看有没有 $VAR 会被当变量展开（值为空）。模板含 $NAME 它。
보인 것: 看有没有 VAR会被当变量展开（值为空）。模板含VAR 会被当变量展开（值为空）。模板含 VAR会被当变量展开（值为空）。模板含NAME 它。
```

이제 **`$` 하나로 둘러싼 형태는 수식으로 보지 않습니다.** `$` 는 수식보다 셸 변수나
가격일 때가 훨씬 많고, 잘못 읽으면 이렇게 문장 자체가 망가지기 때문입니다. 수식을
정말 쓰고 싶을 때를 위한 `$$…$$` 와 `\(…\)` 는 그대로 동작하므로, 수식 표시 기능이
사라지는 것은 아닙니다.

## 함께 고친 것 ②: 로그를 복사해도 정작 필요한 부분이 없던 문제

버그를 알려주실 때 쓰시라고 만든 **"Copy plugin front log"**(명령 패널에서 `copy` 로
검색)는 최근 5,000줄을 담아두고 있었습니다. 넉넉해 보이지만, 답변이 흘러나오는 동안
글자마다 기록이 쌓이기 때문에 실제로는 **1분 20초 남짓**밖에 남지 않았습니다.

이번 제보에서 그대로 드러났습니다. 제보자가 시킨 대로 정확히 복사해 보내주셨는데,
파일이 정확히 상한에 걸려 잘려 있었고 원인을 담은 부분은 이미 밀려난 뒤였습니다. 게다가
그 절반이 위의 `$` 문제가 뿜어낸 경고로 채워져 있었습니다.

이제 줄 수 대신 **32MB 용량**을 기준으로 담습니다. 보통 사용이라면 몇 시간 분량이
남으므로, 앞으로 로그를 보내주실 때는 문제가 일어난 순간이 함께 담깁니다.

## 달라진 점

- **내용 없는 빈 말풍선이 더는 나타나지 않습니다.**
- **도구 실행 결과는 그대로 볼 수 있습니다.** 빈 말풍선을 없애면서 도구가 내놓은
  내용까지 사라지는 일은 없습니다.
- **`$` 가 들어간 문장이 쓴 그대로 보입니다.** 셸 변수나 가격을 이야기해도 문장이
  겹치거나 기호가 사라지지 않습니다.
- **수식은 계속 쓸 수 있습니다.** `$$…$$` 와 `\(…\)` 는 그대로입니다.
- **로그를 복사해 보내주시면 원인이 담깁니다.** 버그를 알려주실 때 훨씬 도움이 됩니다.

## 남아 있는 것

제보자의 화면에서 빈 말풍선이 스무 개 넘게 이어진 이유는, 그 순간의 기록이 위에서
말한 잘림 때문에 남아 있지 않아 끝까지 확인하지 못했습니다. 이번 수정은 **빈 말풍선이
화면에 그려지는 것 자체를 막으므로** 증상은 해결되지만, 그런 메시지가 그토록 많이 오간
까닭은 아직 모릅니다. 로그가 온전히 남게 됐으니, 다시 일어난다면 그때는 원인까지
확인할 수 있습니다.

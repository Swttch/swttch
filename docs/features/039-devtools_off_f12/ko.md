# 개발자 도구가 F12에서 설정으로 옮겨갔습니다

채팅 패널을 한 번 열고 나면, 그 뒤로 `Alt+F12`를 누를 때마다 IDE 터미널 대신
개발자 도구(DevTools) 창이 떴습니다. WebStorm에서 `Alt+F12`는 터미널 도구창을
여는 기본 단축키인데, 그게 동작하지 않게 된 겁니다.

이제 개발자 도구는 **어떤 키에도 걸려 있지 않습니다.** 설정 → IDE 연동의
**개발자 도구** 항목에서 **열기** 버튼으로 엽니다.

## 무엇이 달라졌나

| | 이전 | 지금 |
| --- | --- | --- |
| `F12` | 개발자 도구가 열림 | IDE가 하던 대로 동작 |
| `Alt+F12` | 개발자 도구가 열림 | 터미널 도구창이 열림 |
| 개발자 도구를 열려면 | `F12` | 설정 → IDE 연동 → 개발자 도구 → **열기** |

버튼을 누르면 예전과 똑같은 개발자 도구 창이 별도 창으로 뜹니다. 여는 방법만
바뀌었고 도구 자체는 그대로입니다.

브라우저로 접속해 쓰고 있다면 이 버튼은 비활성으로 보입니다. 그 경우에는
브라우저 자체 개발자 도구를 쓰시면 됩니다.

## 왜 이렇게 바꿨나

키맵을 뒤져도, 레지스트리 설정(`ide.browser.jcef.contextMenu.devTools.enabled`)을
꺼도 증상이 그대로였습니다. 제보해 주신 분이 두 가지를 모두 시도한 뒤에도
안 된다고 알려주셨고, 실제로 그 두 곳은 이 경로와 무관했습니다.

채팅 화면을 그리는 내장 브라우저의 키 처리기가 **IntelliJ의 단축키 체계보다
아래에서** 키를 먼저 받기 때문입니다. 거기서 F12를 가져가 버리면 IDE가 F12에
무엇을 걸어뒀든 닿지 않고, IDE 설정으로는 되돌릴 수단이 없습니다.

처음에는 "수식키가 붙은 F12만 IDE에 넘기자"고 고쳐볼까 했지만, 실제로 키를 눌러
무엇이 오는지 재보니 그 방향이 맞지 않았습니다. **F12만 눌러도 개발자 도구와
터미널이 동시에 열렸습니다.** F12는 IDE가 이미 쓰고 있는 키라, 우리가 거기에
무엇을 걸든 남의 단축키와 겹칩니다.

그래서 조건을 다듬는 대신 **키를 아예 쓰지 않기로** 했습니다. 개발자 도구는
평소에 자주 여는 기능이 아니고, 설정에서 여는 데 드는 몇 번의 클릭보다
키보드를 돌려드리는 쪽이 낫다고 봤습니다.

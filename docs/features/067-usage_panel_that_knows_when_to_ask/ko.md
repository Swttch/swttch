# 언제 물어봐야 하는지 아는 사용량 패널

> 언어: [English](./en.md) · **한국어**

## 무엇이 문제였나

사용량 패널은 같은 질문을 계속 반복했고, 그중 몇 개에는 틀린 답을 그렸습니다.

숫자가 필요할 때마다 `ccb` 프로세스를 돌렸고, 너무 자주 묻는다는 말을 들은 직후에도 그랬습니다. 이름을 아는 창만 그렸기 때문에, API가 몇 주째 보내주던 모델별 한도는 한 번도 나타나지 않았습니다. API 키로 접속한 계정에서는 빈 줄 세 개와 빈 차트를 보여줬는데, 이것은 "여기엔 해당 없음"보다 **"이 제품이 내 플랜을 지원하지 않는구나"**로 읽힙니다.

## 대화에서 직접 갱신됩니다

`claude`는 한 턴이 도는 동안 남은 세션과 주간 한도를 알려줍니다. 원래부터 그랬고, 듣는 쪽이 없었을 뿐입니다.

이제 패널이 그것을 받습니다. 한동안 채팅하시면 막대가 스스로 움직이고, 그러느라 요청을 쓰지 않습니다. **하지 않은 요청은 rate limit에 걸릴 수도 없습니다.**

![대화가 진행되면서 세션 막대가 올라간 사용량 패널](./assets/updated-from-the-conversation.png)

이런 이벤트는 아는 것 전부를 선언하는 것이 아니라 갱신이므로, 이벤트가 언급하지 않은 창은 이전 값을 그대로 유지합니다.

## rate limit 을 맞았으면 그만 묻습니다

API가 "요청이 너무 많다"고 답했을 때 그 안에서 다시 묻는 것은 해결이 아니라 벌을 갱신하는 일입니다. 이제 패널은 API가 요청한 간격만큼 기다리고, 기다리는 동안 비워두는 대신 마지막으로 받아둔 숫자를 보여줍니다.

이 대기는 **계정 하나에만** 적용됩니다. 여러 계정을 함께 갱신하는 것이 정상 동작이므로, 한 계정이 막혔다고 나머지가 침묵하면 안 됩니다.

손으로 새로고침하시면 저장된 값을 건너뛰고 새로 물어봅니다. 다만 **이 대기만은 건너뛰지 않습니다.** 그 반복이 바로 대기가 막으려는 것이기 때문입니다. 조용히 실패하는 대신 얼마나 남았는지 알려드립니다.

## 낡은 숫자를 현재값처럼 보여주지 않습니다

저장해둔 값은 몇 분 동안 재사용합니다. 창을 하나 더 열거나 재시작했다고 해서 같은 그림을 그리려고 요청을 또 쓸 이유가 없기 때문입니다.

다만 창이 리셋을 넘기면 그 즉시 버립니다. 2분 전에 리셋된 5시간 한도는 더 이상 "거의 소진"이 아니고, 남은 시간 동안 옛 숫자를 계속 보여주면 **값이 멈춘 것처럼 보입니다.**

## 모델별 한도가 보입니다

어떤 주간 한도는 모델별로 보고되는데, 그 값은 응답에서 이름이 고정되지 않은 자리에 들어옵니다. 패널은 이름 있는 필드만 읽었기 때문에, API가 보내주는데도 그 한도는 보이지 않았습니다.

이제 API가 붙여준 이름 그대로 그립니다. 다음 달에 새 모델이 나와도 여기서 릴리즈를 낼 필요가 없습니다.

![세션·주간 막대와 함께 모델별 주간 창이 그려진 사용량 패널](./assets/model-scoped-window.png)

이미 그려진 창과 겹치는 항목은 두 번 그리지 않고 버립니다.

## API 키를 쓰는 계정

API 키는 쓴 만큼 과금되므로 보고할 구독 한도가 없습니다. 물어보면 API가 그렇게 답합니다. 게다가 Claude Code는 API 키에도 구독 로그인과 같은 인증 방식을 보고하면서 이메일·조직·플랜은 비워둡니다.

이제 패널은 그 줄을 비워두는 대신 **어떤 자격증명을 쓰는지** 이름을 적고, 한도가 해당하지 않는다는 사실을 말해줍니다. 오류처럼 빨갛게가 아니라, 목록이 비었을 때와 같은 차분한 톤입니다.

![자격증명 소스와 안내 문구가 막대 자리에 표시된 API 키 계정 패널](./assets/api-key-account.png)

`플랜`은 그대로 두었습니다. 나중에 조회할 수 있게 될 수도 있고, 그때까지는 빈 줄이 정직합니다.

## 필요한 것

rate limit 처리와 모델별 창은 최근 `ccb`면 어느 버전이든 동작합니다. [프록시 뒤에서도 사용량 통계가 보입니다](../063-usage_behind_a_proxy/ko.md)에 적은 프록시 정정은 `ccb` 0.6.1 이상이 필요하며, 백엔드가 알아서 설치합니다.

## 여기에 없는 문제라면

[이슈를 열어](https://github.com/Swttch/swttch/issues/new/choose) 알려주세요.

IDE 종류와 버전, 플러그인 버전, 운영체제를 함께 적어주시면 원인을 찾는 데 큰 도움이 됩니다.

Linux 를 쓰신다면 데스크탑 환경(KDE, GNOME 등)과 세션 종류(Wayland, X11)도 알려주세요.

이미 올라온 이슈들은 [이슈 목록](https://github.com/Swttch/swttch/issues)에서 확인하실 수 있습니다.

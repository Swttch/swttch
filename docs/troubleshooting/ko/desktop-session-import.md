# 플러그인에서 만든 세션이 Claude 데스크탑의 Code 탭에 보이지 않습니다

🌐 [English](../en/desktop-session-import.md) | **한국어** | [日本語](../ja/desktop-session-import.md) | [中文](../zh/desktop-session-import.md) | [Español](../es/desktop-session-import.md) | [Deutsch](../de/desktop-session-import.md) | [Français](../fr/desktop-session-import.md)

_최종 업데이트: 2026-11-07_

플러그인에서 만든 세션은 Claude 데스크탑의 Code 탭에 저절로 나타나지 않습니다. 반대 방향, 곧 데스크탑에서 만든 세션을 플러그인에서 여는 것은 처음부터 됩니다. 데스크탑이 목록으로 쓰는 파일은 문서화되어 있지 않아 저희가 대신 고쳐 쓸 수 없고, 대신 **데스크탑에 들어 있는 '세션 가져오기'를 한 번 눌러 주시는 방법**이 있습니다. v0.36.0 부터는 새로 만든 세션이 그 가져오기에 잡히도록 시작되고, 그 전에 만든 세션은 설정 화면의 버튼 한 번으로 준비할 수 있습니다.

## 증상

- 플러그인에서 쓰던 세션이 Claude 데스크탑 Code 탭의 왼쪽 목록에 없습니다
- 같은 폴더에서 터미널의 `claude --resume` 으로는 그 세션이 열립니다. 대화 기록은 그대로 있습니다
- 반대로 데스크탑에서 시작한 세션은 플러그인의 세션 목록에 나타납니다

## 원인

데스크탑은 대화 기록 파일을 그대로 목록으로 보여주지 않고, 자기만의 색인으로 목록을 만듭니다. 기록 파일이 있어도 색인에 오르지 않은 세션은 목록에 나타나지 않습니다.

색인에 올리는 방법이 데스크탑의 **Claude Code CLI 세션 가져오기**입니다. 그런데 이 가져오기는 기록에 `sdk-cli` 라고 적힌 세션을 건너뜁니다. 플러그인은 Claude 를 SDK 도구와 같은 비대화형 방식으로 띄우기 때문에, 이전에는 모든 세션 기록에 `sdk-cli` 가 적혔습니다.

v0.36.0 부터 플러그인은 새 세션을 자기 이름으로 시작합니다. IDE 안에서는 `swttch-jetbrains`, 브라우저(`ccg`)에서는 `swttch-standalone` 입니다. 이 이름은 데스크탑 가져오기가 받아들입니다.

## 해결 방법

### 1. v0.36.0 이전에 만든 세션이 있다면 — 플러그인에서 준비하기

**설정 → 일반 → Claude Desktop 에서 세션을 가져올 수 있도록 준비하기 → 준비**

- 지금 열려 있는 폴더의 세션만 준비합니다. 다른 폴더의 세션은 그 폴더를 연 뒤에 다시 누르세요
- "준비한 세션: N개" 라고 나오면 끝입니다
- 지금 실행 중인 세션은 건드리지 않습니다. "사용 중이라 그대로 둔 세션" 이 보이면 그 세션을 닫고 다시 누르세요
- v0.36.0 이후에 만든 세션만 있다면 이 단계는 건너뛰어도 됩니다

### 2. Claude 데스크탑에서 가져오기

메뉴에서 **도움말 → 문제 해결 → Claude Code CLI 세션 가져오기…** 를 고릅니다.

"Claude Code 세션 N개를 가져오시겠습니까?" 라는 확인창이 뜨면 **세션 가져오기** 를 누릅니다. "세션 N개를 가져왔습니다" 라고 나오면 Code 탭의 목록에서 확인하실 수 있습니다.

- 이 가져오기는 아직 목록에 없는 세션을 **한꺼번에** 가져옵니다. 세션마다 누를 필요가 없고, 플러그인에서 세션을 여러 개 만든 뒤 가끔 한 번 누르시면 됩니다
- 확인창에서 **취소** 를 누르면 아무것도 가져오지 않습니다
- 위 메뉴 위치는 macOS 의 데스크탑 앱에서 확인한 것입니다. Windows 와 Linux 에서는 위치가 다를 수 있습니다

### 3. 이어서 쓰기

가져온 세션에서 메시지를 보내면 같은 대화 기록에 이어서 쌓입니다. 그 세션을 플러그인에서 다시 열면 데스크탑에서 나눈 대화도 함께 보입니다.

한 세션을 두 곳에서 **동시에** 실행하지는 마세요. 같은 기록 파일에 두 프로그램이 쓰게 됩니다. 한쪽에서 끝낸 뒤에 다른 쪽에서 이어 쓰세요.

## 알아 두실 점

- **신뢰한 폴더의 세션만** 가져옵니다. "가져올 CLI 세션 없음" 이라고 나오면, 가져올 수 있는 세션이 이미 목록에 있거나, 이전에 삭제했거나, 아직 Claude 에서 신뢰하지 않은 폴더에 있다는 뜻입니다. 플러그인에서 만든 세션이 안 잡힌다면 1단계를 하셨는지 먼저 확인해 주세요
- 데스크탑에서 **삭제한** 세션은 다시 가져오지 않습니다
- 가져오면 대화 기록과 권한 모드(권한 우회 모드 제외)는 유지되고, 보관 상태와 권한 부여는 유지되지 않습니다
- 1단계의 버튼이 하는 일은 기록 파일의 줄마다 적힌 `sdk-cli` 를 새 이름으로 바꾸는 것뿐이고, 나머지 내용은 그대로입니다. 같은 폴더에서 플러그인이 아닌 다른 SDK 도구가 만든 세션이 있으면 그것도 함께 바뀝니다
- 저희가 데스크탑 앱의 파일을 직접 고쳐 써서 목록에 올리지는 않습니다. 그 파일은 문서화되어 있지 않아서, 데스크탑이 업데이트되면 조용히 깨질 수 있기 때문입니다

### 그래도 안 된다면

같은 폴더에서 터미널의 `claude --resume` 으로 그 세션을 이어 쓰실 수 있습니다.

## Si tu problema no está aquí

Por favor, [abre un issue](https://github.com/Swttch/swttch/issues/new/choose) y cuéntanoslo.

Indicar tu IDE y su versión, la versión del plugin y tu sistema operativo ayuda mucho a encontrar la causa.

Si usas Linux, indica también tu entorno de escritorio (KDE, GNOME, etc.) y el tipo de sesión (Wayland o X11).

Puedes consultar lo que ya se ha reportado en la [lista de issues](https://github.com/Swttch/swttch/issues).

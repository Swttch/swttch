# プラグインで作成したセッションが Claude Desktop の Code タブに表示されません

🌐 [English](../en/desktop-session-import.md) | [한국어](../ko/desktop-session-import.md) | **日本語** | [中文](../zh/desktop-session-import.md) | [Español](../es/desktop-session-import.md) | [Deutsch](../de/desktop-session-import.md) | [Français](../fr/desktop-session-import.md)

_最終更新: 2026-11-07_

プラグインで作成したセッションは、Claude Desktop の Code タブに自動では表示されません。反対方向、つまり Desktop で作成したセッションをプラグインで開くことは、最初から可能です。Desktop が一覧に使っているファイルは公開されていないため、こちらで代わりに書き込むことはできません。その代わりに、**Desktop に備わっている「セッションのインポート」を一度実行していただく方法**があります。v0.36.0 以降は、新しく作成するセッションがこのインポートの対象になるように開始され、それ以前に作成したセッションは設定画面のボタン 1 つで準備できます。

## 症状

- プラグインで使っていたセッションが、Claude Desktop の Code タブ左側の一覧にありません
- 同じフォルダーで、ターミナルの `claude --resume` ならそのセッションを開けます。会話の履歴は残っています
- 反対に、Desktop で開始したセッションはプラグインのセッション一覧に表示されます

## 原因

Desktop は会話の記録ファイルをそのまま一覧にするのではなく、独自のインデックスから一覧を作っています。記録ファイルがあっても、インデックスに載っていないセッションは一覧に表示されません。

インデックスに載せる方法が、Desktop の **Claude Code CLI セッションをインポート** です。ところがこのインポートは、記録に `sdk-cli` と書かれたセッションを読み飛ばします。プラグインは Claude を SDK ツールと同じ非対話の方式で起動するため、以前はすべてのセッションの記録に `sdk-cli` と書かれていました。

v0.36.0 以降、プラグインは新しいセッションを独自の名前で開始します。IDE 内では `swttch-jetbrains`、ブラウザー(`ccg`)では `swttch-standalone` です。この名前は Desktop のインポートが受け付けます。

## 解決方法

### 1. v0.36.0 より前に作成したセッションがある場合 — プラグインで準備する

**設定 → 一般 → Claude Desktop にセッションをインポートできるよう準備する → 準備**

- 開いているフォルダーのセッションだけを準備します。別のフォルダーの分は、そのフォルダーを開いてからもう一度押してください
- 「準備したセッション: N 件」と表示されれば完了です
- 実行中のセッションには触れません。「使用中のためそのままにしたセッション」と表示された場合は、そのセッションを閉じてからもう一度押してください
- すべてのセッションが v0.36.0 以降に作成されたものであれば、この手順は不要です

### 2. Claude Desktop でインポートする

メニューから **ヘルプ → トラブルシューティング → Claude Code CLI セッションをインポート…** を選びます。

「N 件の Claude Code セッションをインポートしますか？」という確認ダイアログが表示されたら、**セッションをインポート** を押します。「インポートしました」と表示されたら、Code タブの一覧で確認できます。

- このインポートは、まだ一覧にないセッションを**まとめて**取り込みます。セッションごとに押す必要はありません。プラグインでセッションをいくつか作ったあとに、ときどき一度押してください
- 確認ダイアログで**キャンセル**を押すと、何もインポートされません
- 上記のメニューの位置は、macOS のデスクトップアプリで確認したものです。Windows と Linux では位置が異なる場合があります

### 3. 続けて使う

インポートしたセッションでメッセージを送ると、同じ会話の記録に追加されます。そのセッションをプラグインで開き直すと、Desktop でやり取りした内容も表示されます。

1 つのセッションを 2 か所で**同時に**実行しないでください。同じ記録ファイルに 2 つのプログラムが書き込むことになります。一方で終えてから、もう一方で続けてください。

## 知っておいていただきたいこと

- インポートされるのは**信頼しているフォルダー**のセッションだけです。「インポートする CLI セッションはありません」と表示された場合は、インポートできるセッションがすでに一覧にあるか、以前に削除されたか、Claude でまだ信頼していないフォルダーにあります。プラグインで作成したセッションが表示されない場合は、まず手順 1 を行ったかご確認ください
- Desktop で**削除した**セッションは、再びインポートされません
- インポートしたセッションは、履歴と許可モード(権限バイパスモードを除く)を保持しますが、アーカイブステータスやアクセス許可の付与は保持しません
- 手順 1 のボタンが行うのは、記録ファイルの各行にある `sdk-cli` を新しい名前に書き換えることだけで、それ以外の内容はそのままです。同じフォルダーに、プラグイン以外の SDK ツールが作成したセッションがある場合は、それも一緒に書き換わります
- Desktop アプリのファイルにこちらから直接書き込んで一覧に載せることは行いません。そのファイルは公開されておらず、Desktop のアップデートで気づかないうちに動かなくなる可能性があるためです

### それでも解決しない場合

同じフォルダーで、ターミナルの `claude --resume` を使ってそのセッションを続けられます。

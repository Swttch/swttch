## Si votre problème ne figure pas ici

Merci d'[ouvrir une issue](https://github.com/Swttch/swttch/issues/new/choose) pour nous en informer.

Préciser votre IDE et sa version, la version du plugin et votre système d'exploitation aide beaucoup à trouver la cause.

Sous Linux, indiquez également votre environnement de bureau (KDE, GNOME, etc.) et le type de session (Wayland ou X11).

Vous pouvez consulter ce qui a déjà été signalé dans la [liste des issues](https://github.com/Swttch/swttch/issues).

## Wenn Ihr Problem hier nicht steht

Bitte [eröffnen Sie ein Issue](https://github.com/Swttch/swttch/issues/new/choose) und schildern Sie es uns.

Wenn Sie Ihre IDE samt Version, die Plugin-Version und Ihr Betriebssystem angeben, hilft das sehr bei der Ursachensuche.

Unter Linux nennen Sie bitte auch Ihre Desktop-Umgebung (KDE, GNOME und so weiter) und die Art der Sitzung (Wayland oder X11).

Was bereits gemeldet wurde, finden Sie in der [Issue-Liste](https://github.com/Swttch/swttch/issues).
